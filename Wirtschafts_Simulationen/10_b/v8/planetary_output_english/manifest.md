# Planetary economy simulation: extended effect economy

This simulation does not model a national economy with money, prices, gross domestic product, wages, profit, rent, or foreign-trade values.
It models a planetary effect economy: needs, materials, potencies, ecological boundaries, time contributions, capacities, sectors, and social feedback.

## Core principle

An economic action is not a buy or sell transaction here, but a change of state:

```
phenomenon + causality + time + intensity + existence + potencies + effects + substance + matter + difference + determination + phenomena + angle direction → effect contract → changed reality
```
