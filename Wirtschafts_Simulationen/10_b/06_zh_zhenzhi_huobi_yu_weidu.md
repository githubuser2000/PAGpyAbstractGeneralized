# 为什么这种堆叠真值货币会导向这些维度？

## 问题

为什么这种堆叠真值货币会导向这些维度，例如因果性？

## 回答

因为这种“货币”**衡量的不是价值**，而是**行动的真实性**。

普通货币大致回答这些问题：

```text
某物值多少？
某人能支付多少？
交换了多少？
```

堆叠真值货币回答的则是：

```text
需要是否真实？
原因是什么？
有多紧急？
有多强烈？
存在哪些手段？
会产生什么作用？
行动是否指向正确方向？
```

因此会出现像**因果性**这样的维度。一旦经济不再由价格、数量和所有权来控制，它就必须知道**为什么**要做某事，以及行动是否**真的触及原因**。

## 核心

在你的系统中，经济行动不是这样的购买：

```text
我用价格 Y 购买商品 X。
```

而更接近于：

```text
一个真实状态被改变。
```

也就是：

```text
之前的状态 → 行动 → 之后的状态
```

为了让这件事运作，系统需要维度。因为每个行动都有多个真实性问题。

例如：

```text
饥饿存在。
但是为什么？
```

可能的原因包括：

```text
食物太少
分配不良
缺少冷藏
运输路线损坏
干旱
贫困
战争
错误规划
食物浪费
```

如果系统只看到“饥饿 = 高”，它可能会错误行动。

但如果它衡量**因果性**，它就会问：

```text
这个行动是否触及饥饿的原因？
```

这就是为什么因果性会成为一个独立维度。

## 为什么不能只有一个真值？

因为单一数值太粗糙。

如果把一切压缩成一个数字，就会再次发生类似金钱的问题：

```text
一切都变得可比较，
但许多东西变得不可见。
```

价格会让很多东西不可见：

```text
自然破坏
照护劳动
紧急性
真正原因
社会后果
未来损害
地方特殊性
权力关系
```

堆叠真值正是为了防止这种情况。

所以它不是：

```text
真值 = 87 分
```

而是：

```text
真值 = [因果性、时间、强度、存在、潜能、作用、
        实质、物质、差异、决定、现象、角向]
```

也就是说，它是一个堆叠。

不是一个单值。  
而是**现实的多层签名**。

## 例子：因果性

假设一个公社存在无家可归问题。

如果没有因果性维度，系统可能会说：

```text
住房需要高 → 建造新房屋
```

但原因也许不是住房空间不足，而是：

```text
空置房屋
错误分配
租金过高
缺乏修缮
投机
社会排斥
缺少无障碍条件
```

那么新建住房也许不是正确行动。

有了因果性，系统会问：

```text
新建住房真的有帮助吗？
还是利用空置房屋有帮助？
还是修缮？
还是重新分配？
还是社会支持？
```

因此，**因果性**这个维度可以防止盲目行动主义。

它说：

```text
不是每一种作用都是正确作用。
一个行动只有在触及原因时才是好的。
```

## 为什么正是这些维度？

因为每个经济行动至少都需要这些问题。

| 维度 | 为什么需要它 |
|---|---|
| **因果性** | 行动触及原因，还是只触及症状？ |
| **时间** | 必须立刻行动，还是可以稍后行动？ |
| **强度** | 需要、损害或作用有多强？ |
| **存在** | 问题真的存在，还是只是被声称？ |
| **潜能** | 是否有能力、手段和解决可能？ |
| **作用** | 行动在系统中改变了什么？ |
| **实质** | 有哪些材料、能源、食物、照护时间或资源可用？ |
| **物质** | 真实基础设施或资源位于哪里？ |
| **差异** | 需要与现实之间的缺口有多大？ |
| **决定** | 行动是否被社会地、民主地、有意义地决定？ |
| **现象** | 状态如何以可见、可测量或可经验的方式显现？ |
| **角向** | 行动是再生性的、中性的、有害的，还是控制性的？ |

这些维度之所以出现，是因为一个星球经济不能只知道：

```text
它花多少钱？
```

它必须知道：

```text
发生了什么？
为什么发生？
有多紧急？
可以做什么？
有哪些手段可用？
会产生什么后果？
是否符合星球边界？
是否具有社会正当性？
```

## 因此，这种“货币”不是购买力

如果你仍然称它为“货币”，那它是一种不同类型的货币。

不是：

```text
金钱货币 = 购买的要求权
```

而是：

```text
真值货币 = 获得关注、优先级和行动的要求权
```

或者：

```text
金钱问：谁能支付？
真值堆叠问：什么是真正必要和正确的？
```

这就是决定性的区别。

## 堆叠如何工作

例子：

```text
334434234343
```

这不是金钱数量。它是一个编码序列：

```text
C  = 3  因果性
T  = 3  时间
I  = 4  强度
E  = 4  存在
P  = 3  潜能
Ef = 4  作用
S  = 2  实质
M  = 3  物质
D  = 4  差异
De = 3  决定
Ph = 4  现象
R  = 3  角向
```

读出来，它的意思是：

```text
原因被很好识别。
情况很紧急。
问题很强烈。
它确实存在。
存在解决可能。
作用会很高。
实质只部分可用。
物质状况足够。
需要缺口很大。
社会决定很强。
现象可见。
方向基本正确。
```

这比下面这种说法精确得多：

```text
价格 = 100
```

## 为什么因果性不能被作用取代

有人可能会问：

```text
作用这个维度不够吗？
```

不够。

一个行动可能有作用，但仍然触及了错误的原因。

健康例子：

```text
止痛药有作用。
但如果原因是被污染的水，
就必须解决水的问题。
```

所以：

```text
作用 = 发生了什么？
因果性 = 是否触及源头？
```

两者都必要。

## 为什么因果性不能被差异取代

差异也不够。

```text
差异 = 缺少某物。
因果性 = 为什么缺少它？
```

食物例子：

```text
差异高：人们食物太少。
```

但原因可能是：

```text
干旱
运输失败
缺乏储存
分配不公
土壤破坏
种子短缺
能源故障
```

根据不同原因，需要不同的行动。

因此，因果性是一个独立维度。

## 为什么因果性不能被民主取代

决定也不够。

多数人可能想要某件事，但仍然在因果上判断错误。

例子：

```text
很多人想用更多道路解决堵车。
```

但堵车的原因可能是：

```text
城市蔓延
缺少公共交通
错误的工作时间安排
糟糕的城市规划
```

那么修建更多道路从长期来看甚至可能加重拥堵。

所以：

```text
决定 = 是否具有社会正当性？
因果性 = 在原因上是否事实正确？
```

两者必须结合。

## 堆叠真值会产生契约条件

这些维度不是装饰。它们会改变行动。

例如：

```text
因果性低
时间高
强度高
```

这意味着：

```text
情况紧急且强烈，
但原因不清楚。
```

那么契约就不应该被盲目完全执行，而应该是：

```text
立即紧急帮助
同时调查原因
之后有纠正义务
```

另一个例子：

```text
差异高
实质低
角向低
```

这意味着：

```text
需要是真实的，
手段是稀缺的，
计划行动具有有害作用。
```

那么：

```text
不要直接放行
寻找替代方案
检查修理 / 改造 / 重新分配
```

## 最重要的一点

这些维度之所以出现，是因为你的系统想要**取代作为买卖的交易/行动**。

购买和出售过去是非常简单的代码：

```text
购买 = 我用钱拿走某物。
出售 = 我用钱交出某物。
```

在你的系统中，它变成：

```text
购买 = 接受一个必要作用。
出售 = 贡献能力、时间、实质或作用。
```

但这样一来，就必须知道：

```text
哪种作用？
为什么？
什么时候？
多强？
由什么构成？
在哪里？
为了谁？
会有什么后果？
朝哪个方向？
```

维度正是由此产生的。

## 简短形式

堆叠真值货币会导向因果性和其他维度，因为它**用现实逻辑替代价格逻辑**。

价格问：

```text
多少？
```

真值堆叠问：

```text
为什么？
什么时候？
多强？
它是否存在？
什么是可能的？
它造成什么？
它由什么构成？
它在哪里？
缺少什么？
谁来决定？
它如何显现？
它朝哪个方向起作用？
```

或者非常简短地说：

```text
金钱协调交换。
真值协调现实。
```

这就是为什么这种货币需要像**因果性**这样的维度。没有因果性，系统也会行动，但可能会在现实的错误位置行动。
