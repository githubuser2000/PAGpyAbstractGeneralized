# Extrem bunte UTF-8-Art-Galerie

Diese Version ergänzt die Terminalausgabe **unter den sichtbaren Wirkungsverträgen** um eine große Galerie farbiger UTF-8/ANSI-Diagramme.

## Start mit voller Anzeige

```bash
pypy3 planetary_effect_economy.py \
  --steps 120 \
  --scenario planetary_commons \
  --out out_planetenwirtschaft \
  --show-trades 40 \
  --show-trade-detail \
  --show-dimensions \
  --show-catalog \
  --show-stack-explanation \
  --show-art 30
```

Ohne PyPy3:

```bash
python3 planetary_effect_economy.py \
  --steps 120 \
  --scenario planetary_commons \
  --out out_planetenwirtschaft \
  --show-trades 40 \
  --show-trade-detail \
  --show-dimensions \
  --show-catalog \
  --show-stack-explanation \
  --show-art 30
```

## Neue Optionen

```text
--show-art N       zeigt N UTF-8/ANSI-Art-Diagramme unter den Verträgen; Standard: 30
--show-art 0       schaltet die Galerie aus
--force-color      erzwingt ANSI-Farben auch beim Umleiten/Pipen
--no-color         deaktiviert ANSI-Farben
```

## Bedeutung

Die Visualisierungen zeigen, dass Handel hier nicht als Werttausch erscheint, sondern als farbige Wirkungskoordination:

```text
Kausalität + Zeit + Intensität + Existenz + Potenzen + Wirkungen
+ Substanz + Materie + Differenz + Bestimmung + Phänomene + Winkelrichtung
→ Wirkungsvertrag
```
