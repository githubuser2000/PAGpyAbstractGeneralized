# Modellnotizen: erweiterte Planetenwirtschaft

## 1. Grundsatz

Diese Simulation ist keine Volkswirtschaft mit Geld, Preis, Marktwert und BIP. Sie ist eine **Planetenwirtschaft**:

```text
Bedürfnis + Substanz + Materie + Zeit + Potenzen + Wirkung + Richtung
→ koordinierte Handlung
→ veränderte Wirklichkeit
```

Die alten Kategorien werden ersetzt:

```text
Wert        → Wirkung / Priorität / Differenz
Menge       → Aktivierungsgrad / Deckung / Kapazität
Ding        → Phänomen / Zustand / Substanz-Materie-Komplex
Kaufen      → Bedürfniswirkung annehmen
Verkaufen   → Fähigkeit, Zeit, Substanz oder Wirkung beitragen
Handel      → kausaler Wirkungsfluss
```

## 2. Wahrheitsvektor

Jedes Handlungsfeld bekommt gestapelte logische Wahrheitswerte:

```text
causality
time
intensity
existence
potencies
effects
substance
matter
difference
determination
phenomena
angle_direction
```

Diese Werte erzeugen keine Preise. Sie erzeugen eine **Priorität der Wirklichkeitskorrektur**.

## 3. Erweiterte Makroökonomie ohne Geld

Die erweiterte Version ergänzt, was zu einer Volkswirtschaft gehört, ohne die Geldlogik zu übernehmen:

- Sektorenrechnung: Domains werden Sektoren der planetaren Reproduktion zugeordnet.
- Arbeits-/Zeitrechnung: verfügbare produktive Zeit wird nicht verkauft, sondern als Beitrag gelenkt.
- Kapazitätsrechnung: Wohnen, Pflege, Bildung, Mobilität, Produktion, Lagerung, Governance, Wissen, Resilienz.
- Verteilungsrechnung: Ungleichheit wird als Unterschied in Versorgung/Wohlbefinden gemessen.
- Außenwirtschaftsersatz: globale Transfers sind innerplanetare Wirkungsflüsse.
- Investitionsersatz: Kapazitätsaufbau statt Kapitalrendite.
- Staatsersatz: Governance-Kapazität, demokratische Rückkopplung, Wahrheitskorrektur.
- Kreislaufrechnung: Abfall wird als Materialdifferenz modelliert.

## 4. Neue Handlungsfelder

Zusätzlich zu Wasser, Nahrung, Energie, Wohnen, Gesundheit, Pflege, Bildung, Mobilität, Reparatur, Ökologie und Abfall gibt es:

```text
manufacturing  = Grundindustrie, Werkzeuge, Ersatzteile
storage        = Lager, Puffer, Stromspeicher, Vorratssicherheit
governance     = demokratische Koordination und Fehlerkorrektur
knowledge      = Forschung, offene Pläne, technisches Lernen
resilience     = Notfallfähigkeit, Redundanz, Schockabsorption
```

## 5. Handelslogik

Die Datei `effect_flow_audit.csv` zeigt, wie Handeln ersetzt wird:

```text
contribution_offer = früher: verkaufen / Arbeit anbieten
need_acceptance    = früher: kaufen / konsumieren / mieten
planetary_transfer = früher: Handel / Import / Export
```

Jede Zeile trägt die Wahrheitswerte mit. Dadurch wird sichtbar, warum eine Wirkung aktiviert wurde.

## 6. Grenzen des Modells

Das Modell ist synthetisch. Es ist keine empirische Prognose. Es eignet sich für:

- Theorieentwicklung,
- Spielmechanik,
- Simulationsdesign,
- politische Szenarioarbeit,
- Prüfung von Wirkungslogiken.

Die absolute Zahl ist weniger wichtig als die Richtung: Werden Grundbedürfnisse gedeckt, Grenzüberschreitungen reduziert, Wahrheitsfehler kleiner, Autonomie erhalten und Stoffkreisläufe verbessert?
