# ¿Por qué una moneda de valores de verdad apilados conduce a dimensiones como la causalidad?

## Pregunta

¿Por qué esta moneda de valores de verdad apilados conduce a esas dimensiones, por ejemplo la **causalidad**?

## Respuesta

Porque esta “moneda” no mide **valor monetario**, sino **verdad de acción**. Una moneda normal pregunta, de forma aproximada:

```text
¿Cuánto vale algo?
¿Cuánto puede pagar alguien?
¿Cuánto se intercambia?
```

Una moneda de valores de verdad apilados pregunta otra cosa:

```text
¿La necesidad es real?
¿Cuál es la causa?
¿Qué tan urgente es?
¿Qué tan intensa es?
¿Qué medios y capacidades existen?
¿Qué efectos se producirán?
¿La acción está orientada correctamente?
```

Por eso aparecen dimensiones como **causalidad**. Cuando la economía deja de coordinarse mediante precio, cantidad y propiedad, debe saber **por qué** se actúa y **si** la acción toca realmente la causa del estado.

## Núcleo del concepto

En este sistema una acción económica no es principalmente:

```text
Compro la mercancía X por el precio Y.
```

Sino:

```text
Un estado real es transformado.
```

Es decir:

```text
estado anterior → acción → estado posterior
```

Para que eso funcione, el sistema necesita dimensiones. Toda acción contiene varias preguntas de verdad. Por ejemplo, puede existir hambre, pero la causa puede ser falta de alimentos, mala distribución, refrigeración insuficiente, transporte roto, sequía, guerra, mala planificación o desperdicio.

Si el sistema solo ve “hambre alta”, puede actuar mal. Si mide **causalidad**, pregunta:

```text
¿Esta acción toca la causa del hambre?
```

La causalidad evita el activismo ciego.

## Por qué no basta un único valor

Un solo valor es demasiado tosco. Si todo se comprime en una cifra, sucede algo parecido al dinero: todo se vuelve comparable, pero mucho se vuelve invisible. El precio puede ocultar destrucción natural, trabajo de cuidados, urgencia, causa real, daños futuros, particularidades locales y relaciones de poder.

Por eso el valor de verdad apilado no es:

```text
verdad = 87 puntos
```

sino una firma de realidad:

```text
[causalidad, tiempo, intensidad, existencia, potencias, efectos,
 sustancia, materia, diferencia, determinación, fenómenos, dirección angular]
```

## Las dimensiones

| Dimensión | Por qué es necesaria |
|---|---|
| Causalidad | ¿La acción toca la causa o solo un síntoma? |
| Tiempo | ¿Hay que actuar ahora o se puede planificar? |
| Intensidad | ¿Qué tan fuertes son la necesidad, el daño o el efecto? |
| Existencia | ¿El problema existe realmente o solo se afirma? |
| Potencias | ¿Qué capacidades, herramientas y caminos de solución existen? |
| Efectos | ¿Qué cambia la acción en el sistema? |
| Sustancia | ¿Qué materiales, energía, alimentos, tiempo de cuidado o saber están disponibles? |
| Materia | ¿Dónde están realmente recursos e infraestructura? |
| Diferencia | ¿Cuál es la brecha entre necesidad y realidad? |
| Determinación | ¿La acción está social y democráticamente determinada? |
| Fenómenos | ¿Cómo aparece, se mide o se informa el estado? |
| Dirección angular | ¿La acción regenera, es neutral, daña o controla? |

## Ejemplo de pila

```text
334434234343
```

No es una suma de dinero. Se lee así:

```text
causalidad=3, tiempo=3, intensidad=4, existencia=4,
potencias=3, efectos=4, sustancia=2, materia=3,
diferencia=4, determinación=3, fenómenos=4, dirección=3
```

Esto significa: la causa está bastante clara, el estado es urgente, el fenómeno es fuerte y real, hay posibilidades de solución, el efecto sería alto, pero la sustancia disponible es limitada. Por tanto el contrato debe contener condiciones.

## Por qué la causalidad no es lo mismo que efecto, diferencia o democracia

**Efecto** pregunta qué ocurre. **Causalidad** pregunta si se toca el origen. Un analgésico produce efecto, pero si la causa es agua contaminada, hay que corregir el agua.

**Diferencia** dice que algo falta. **Causalidad** dice por qué falta. El hambre puede venir de sequía, mala distribución, falta de energía o destrucción del suelo.

**Determinación** dice que una acción tiene legitimidad social. Pero una mayoría también puede equivocarse causalmente. Por eso hacen falta verdad causal y determinación social juntas.

## Resumen

El dinero coordina intercambio. Los valores de verdad apilados coordinan realidad. Por eso necesitan dimensiones como la causalidad: sin causalidad el sistema puede actuar mucho, pero en el lugar equivocado de la realidad.
