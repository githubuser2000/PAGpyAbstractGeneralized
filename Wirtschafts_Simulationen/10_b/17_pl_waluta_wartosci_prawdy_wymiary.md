# Dlaczego waluta ułożonych wartości prawdy prowadzi do takich wymiarów jak przyczynowość?

## Pytanie

Dlaczego ta waluta ułożonych wartości prawdy prowadzi do tych wymiarów, na przykład do **przyczynowości**?

## Odpowiedź

Ponieważ ta „waluta” nie mierzy **wartości pieniężnej**, lecz **prawdę działania**. Zwykła waluta pyta w przybliżeniu:

```text
Ile coś jest warte?
Ile ktoś może zapłacić?
Ile zostaje wymienione?
```

Waluta ułożonych wartości prawdy pyta zamiast tego:

```text
Czy potrzeba jest realna?
Jaka jest przyczyna?
Jak pilna jest sytuacja?
Jak silne jest zjawisko?
Jakie środki i zdolności istnieją?
Jakie skutki powstaną?
Czy kierunek działania jest właściwy?
```

Dlatego pojawiają się wymiary takie jak **przyczynowość**. Gdy gospodarka nie jest już koordynowana przez cenę, ilość i własność, musi wiedzieć **dlaczego** działa i **czy** działanie naprawdę dotyka przyczyny stanu.

## Rdzeń

W tym systemie działanie gospodarcze nie jest przede wszystkim:

```text
Kupuję towar X za cenę Y.
```

lecz:

```text
Rzeczywisty stan zostaje przekształcony.
```

Czyli:

```text
stan przed → działanie → stan po
```

Aby to działało, system potrzebuje wymiarów. Każde działanie zawiera kilka pytań o prawdę. Głód może istnieć, ale jego przyczyną może być brak żywności, zła dystrybucja, brak chłodzenia, uszkodzony transport, susza, wojna, złe planowanie albo marnowanie żywności.

Jeśli system widzi tylko „wysoki głód”, może działać błędnie. Jeśli mierzy **przyczynowość**, pyta:

```text
Czy to działanie dotyka przyczyny głodu?
```

Przyczynowość chroni przed ślepym aktywizmem.

## Dlaczego nie wystarczy jedna wartość?

Jedna wartość jest zbyt gruba. Jeśli wszystko zostanie ściśnięte w jedną liczbę, dzieje się coś podobnego jak z pieniądzem: wszystko staje się porównywalne, ale wiele rzeczy znika. Cena może ukryć niszczenie natury, pracę opiekuńczą, pilność, prawdziwą przyczynę, szkody przyszłe, lokalne szczegóły i relacje władzy.

Dlatego ułożona wartość prawdy nie jest:

```text
prawda = 87 punktów
```

lecz wielowymiarową sygnaturą:

```text
[przyczynowość, czas, intensywność, istnienie, potencje, skutki,
 substancja, materia, różnica, określenie, zjawiska, kierunek kątowy]
```

## Wymiary

| Wymiar | Dlaczego jest potrzebny |
|---|---|
| Przyczynowość | Czy działanie dotyka przyczyny, czy tylko objawu? |
| Czas | Czy trzeba działać natychmiast, czy można planować? |
| Intensywność | Jak silna jest potrzeba, szkoda lub skutek? |
| Istnienie | Czy problem naprawdę istnieje, czy jest tylko twierdzeniem? |
| Potencje | Jakie zdolności, narzędzia i drogi rozwiązania istnieją? |
| Skutki | Co działanie zmienia w systemie? |
| Substancja | Jakie materiały, energia, żywność, czas opieki lub wiedza są dostępne? |
| Materia | Gdzie rzeczywiście znajdują się zasoby i infrastruktura? |
| Różnica | Jaka jest luka między potrzebą a rzeczywistością? |
| Określenie | Czy działanie jest społecznie i demokratycznie określone? |
| Zjawiska | Jak stan się ukazuje, jest mierzony lub zgłaszany? |
| Kierunek kątowy | Czy działanie regeneruje, jest neutralne, szkodzi czy kontroluje? |

## Przykład stosu

```text
334434234343
```

To nie jest suma pieniędzy. Odczyt jest taki:

```text
przyczynowość=3, czas=3, intensywność=4, istnienie=4,
potencje=3, skutki=4, substancja=2, materia=3,
różnica=4, określenie=3, zjawiska=4, kierunek=3
```

Znaczy to: przyczyna jest dość dobrze rozpoznana, sytuacja jest pilna, zjawisko jest silne i realne, istnieją możliwości rozwiązania, oczekiwany skutek jest wysoki, ale dostępna substancja jest ograniczona. Umowa musi więc zawierać warunki.

## Dlaczego przyczynowość jest osobna?

**Skutek** mówi, co się dzieje. **Przyczynowość** mówi, czy dotykamy źródła. Lek przeciwbólowy działa, ale jeśli przyczyną choroby jest skażona woda, trzeba naprawić wodę.

**Różnica** mówi, że czegoś brakuje. **Przyczynowość** mówi, dlaczego brakuje. Głód może wynikać z suszy, złej dystrybucji, braku energii albo zniszczenia gleby.

**Określenie** mówi, że działanie ma legitymację społeczną. Ale większość też może mylić się co do przyczyny. Potrzebne są więc prawda przyczynowa i określenie społeczne.

## Podsumowanie

Pieniądz koordynuje wymianę. Ułożone wartości prawdy koordynują rzeczywistość. Dlatego potrzebują wymiarów takich jak przyczynowość: bez niej system może działać dużo, ale w złym miejscu rzeczywistości.
