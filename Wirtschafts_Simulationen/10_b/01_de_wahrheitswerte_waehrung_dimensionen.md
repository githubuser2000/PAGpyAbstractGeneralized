# Warum führt diese gestapelte Wahrheitswerte-Währung zu diesen Dimensionen?

## Frage

Warum führt diese gestapelte Wahrheitswerte Währung zu diesen Dimensionen, wie z.B. Kausalität?

## Antwort

Weil diese „Währung“ **nicht Wert misst**, sondern **Handlungswahrheit**.

Eine normale Geldwährung beantwortet grob:

```text
Wie viel ist etwas wert?
Wie viel kann jemand bezahlen?
Wie viel wird getauscht?
```

Eine gestapelte Wahrheitswerte-Währung beantwortet stattdessen:

```text
Ist der Bedarf real?
Was ist die Ursache?
Wie dringend ist es?
Wie stark ist es?
Welche Mittel existieren?
Welche Wirkung entsteht?
Ist die Handlung richtig gerichtet?
```

Darum entstehen Dimensionen wie **Kausalität**. Sobald Wirtschaft nicht mehr über Preis, Menge und Eigentum gesteuert wird, muss sie wissen, **warum** etwas getan wird und **ob** die Handlung tatsächlich die Ursache trifft.

## Der Kern

In deinem System ist eine wirtschaftliche Handlung kein Kauf wie:

```text
Ich kaufe Ware X für Preis Y.
```

Sondern eher:

```text
Ein realer Zustand wird verändert.
```

Also:

```text
Zustand vorher → Handlung → Zustand nachher
```

Damit das funktioniert, braucht das System Dimensionen. Denn jede Handlung hat mehrere Wahrheitsfragen.

Zum Beispiel:

```text
Hunger existiert.
Aber warum?
```

Mögliche Ursachen:

```text
zu wenig Nahrung
schlechte Verteilung
fehlende Kühlung
kaputte Transportwege
Dürre
Armut
Krieg
falsche Planung
Lebensmittelverschwendung
```

Wenn das System nur „Hunger = hoch“ sieht, kann es falsch handeln.

Wenn es aber **Kausalität** misst, fragt es:

```text
Trifft diese Handlung die Ursache des Hungers?
```

Das ist der Grund, warum Kausalität eine eigene Dimension wird.

## Warum nicht einfach ein einziger Wahrheitswert?

Weil ein einziger Wert zu grob wäre.

Wenn du alles in eine Zahl presst, passiert wieder etwas Ähnliches wie bei Geld:

```text
Alles wird vergleichbar,
aber vieles wird unsichtbar.
```

Preis macht vieles unsichtbar:

```text
Naturzerstörung
Pflegearbeit
Dringlichkeit
echte Ursache
soziale Folgen
Zukunftsschäden
lokale Besonderheiten
Machtverhältnisse
```

Der gestapelte Wahrheitswert soll genau das verhindern.

Darum ist er nicht:

```text
Wahrheit = 87 Punkte
```

sondern:

```text
Wahrheit = [Kausalität, Zeit, Intensität, Existenz, Potenzen, Wirkungen,
            Substanz, Materie, Differenz, Bestimmung, Phänomene, Winkelrichtung]
```

Also ein Stapel.

Nicht ein Wert.  
Sondern eine **mehrschichtige Signatur der Wirklichkeit**.

## Beispiel: Kausalität

Angenommen eine Kommune hat Wohnungslosigkeit.

Ohne Kausalitätsdimension könnte das System sagen:

```text
Wohnungsbedarf hoch → neue Häuser bauen
```

Aber vielleicht ist die Ursache nicht fehlender Wohnraum, sondern:

```text
Leerstand
falsche Zuteilung
zu hohe Mieten
fehlende Sanierung
Spekulation
soziale Ausgrenzung
fehlende Barrierefreiheit
```

Dann wäre Neubau vielleicht nicht die richtige Handlung.

Mit Kausalität fragt das System:

```text
Hilft Neubau wirklich?
Oder hilft Leerstandsnutzung?
Oder Sanierung?
Oder Umverteilung?
Oder soziale Begleitung?
```

Die Dimension **Kausalität** verhindert also blinden Aktionismus.

Sie sagt:

```text
Nicht jede Wirkung ist eine richtige Wirkung.
Eine Handlung ist nur gut, wenn sie die Ursache trifft.
```

## Warum genau diese Dimensionen?

Weil jede wirtschaftliche Handlung mindestens diese Fragen braucht.

| Dimension | Warum sie nötig ist |
|---|---|
| **Kausalität** | Trifft die Handlung die Ursache oder nur ein Symptom? |
| **Zeit** | Muss sofort gehandelt werden oder später? |
| **Intensität** | Wie stark ist Bedarf, Schaden oder Wirkung? |
| **Existenz** | Existiert das Problem wirklich oder wird es nur behauptet? |
| **Potenzen** | Gibt es Fähigkeiten, Mittel und Möglichkeiten zur Lösung? |
| **Wirkungen** | Was verändert die Handlung im System? |
| **Substanz** | Welche Stoffe, Energie, Nahrung, Pflegezeit oder Materialien sind vorhanden? |
| **Materie** | Wo befindet sich die reale Infrastruktur oder Ressource? |
| **Differenz** | Wie groß ist die Lücke zwischen Bedarf und Wirklichkeit? |
| **Bestimmung** | Ist die Handlung sozial, demokratisch und sinnvoll bestimmt? |
| **Phänomene** | Wie zeigt sich der Zustand sichtbar, messbar oder erfahrbar? |
| **Winkelrichtung** | Wirkt die Handlung regenerativ, neutral, schädlich oder kontrollierend? |

Diese Dimensionen entstehen also, weil eine Planetenwirtschaft nicht nur wissen darf:

```text
Was kostet es?
```

Sondern wissen muss:

```text
Was ist los?
Warum ist es los?
Wie dringend ist es?
Was kann getan werden?
Welche Mittel gibt es?
Welche Folgen entstehen?
Ist es planetar tragfähig?
Ist es sozial legitim?
```

## Die „Währung“ ist also keine Kaufkraft

Wenn du sie trotzdem „Währung“ nennst, dann ist sie eine andere Art von Währung.

Nicht:

```text
Geldwährung = Anspruch auf Kauf
```

Sondern:

```text
Wahrheitswert-Währung = Anspruch auf Beachtung, Priorität und Handlung
```

Oder:

```text
Geld sagt: Wer kann zahlen?
Wahrheitsstapel sagt: Was ist wirklich nötig und richtig?
```

Das ist der entscheidende Unterschied.

## Wie der Stapel funktioniert

Beispiel:

```text
334434234343
```

Das ist keine Geldsumme. Es ist eine codierte Reihenfolge:

```text
K  = 3  Kausalität
Z  = 3  Zeit
I  = 4  Intensität
E  = 4  Existenz
P  = 3  Potenzen
W  = 4  Wirkungen
S  = 2  Substanz
M  = 3  Materie
D  = 4  Differenz
B  = 3  Bestimmung
Ph = 4  Phänomene
R  = 3  Winkelrichtung
```

Gelesen heißt das:

```text
Die Ursache ist gut erkannt.
Die Lage ist dringend.
Das Problem ist intensiv.
Es existiert wirklich.
Es gibt Lösungsmöglichkeiten.
Die Wirkung wäre hoch.
Die Substanz ist nur teilweise vorhanden.
Die materielle Lage ist ausreichend.
Die Bedarfslücke ist groß.
Die soziale Bestimmung ist stark.
Das Phänomen ist sichtbar.
Die Richtung ist überwiegend richtig.
```

Das ist viel genauer als:

```text
Preis = 100
```

## Warum Kausalität nicht durch Wirkung ersetzt werden kann

Man könnte fragen:

```text
Reicht nicht die Dimension Wirkung?
```

Nein.

Denn eine Handlung kann Wirkung haben, aber trotzdem die falsche Ursache treffen.

Beispiel Gesundheit:

```text
Schmerzmittel wirken.
Aber wenn die Ursache vergiftetes Wasser ist,
muss das Wasserproblem gelöst werden.
```

Also:

```text
Wirkung = Was passiert?
Kausalität = Trifft es den Ursprung?
```

Beides ist nötig.

## Warum Kausalität nicht durch Differenz ersetzt werden kann

Auch Differenz reicht nicht.

```text
Differenz = Es fehlt etwas.
Kausalität = Warum fehlt es?
```

Beispiel Nahrung:

```text
Differenz hoch: Menschen haben zu wenig Nahrung.
```

Aber Ursache könnte sein:

```text
Dürre
Transportausfall
fehlende Lagerung
ungerechte Verteilung
Bodenzerstörung
Saatgutmangel
Energieausfall
```

Je nach Ursache braucht es andere Handlung.

Darum ist Kausalität eine eigene Dimension.

## Warum Kausalität nicht durch Demokratie ersetzt werden kann

Auch Bestimmung reicht nicht.

Eine Mehrheit kann etwas wollen, aber kausal falsch liegen.

Beispiel:

```text
Viele wollen mehr Straßen gegen Stau.
```

Aber die Ursache des Staus kann sein:

```text
Zersiedelung
fehlender Nahverkehr
falsche Arbeitszeiten
schlechte Stadtplanung
```

Dann kann mehr Straßenbau langfristig den Stau sogar verstärken.

Also:

```text
Bestimmung = Ist es sozial legitimiert?
Kausalität = Ist es sachlich ursachenrichtig?
```

Beides muss zusammenkommen.

## Der gestapelte Wahrheitswert erzeugt Vertragsbedingungen

Die Dimensionen sind nicht nur Dekoration. Sie ändern die Handlung.

Beispiel:

```text
Kausalität niedrig
Zeit hoch
Intensität hoch
```

Das bedeutet:

```text
Es ist dringend und stark,
aber die Ursache ist unklar.
```

Dann sollte der Vertrag nicht blind voll ausgeführt werden, sondern:

```text
Notfallhilfe sofort
Ursachenprüfung parallel
spätere Korrekturpflicht
```

Anderes Beispiel:

```text
Differenz hoch
Substanz niedrig
Winkelrichtung niedrig
```

Das bedeutet:

```text
Bedarf ist real,
Mittel sind knapp,
und die geplante Handlung wirkt schädlich.
```

Dann:

```text
nicht einfach freigeben
Alternative suchen
Reparatur / Umbau / Umverteilung prüfen
```

## Der wichtigste Punkt

Die Dimensionen entstehen, weil dein System **Handeln ersetzen will**.

Kaufen und Verkaufen waren früher sehr einfache Codes:

```text
Kaufen = Ich nehme etwas gegen Geld.
Verkaufen = Ich gebe etwas gegen Geld.
```

In deinem System wird daraus:

```text
Kaufen = eine notwendige Wirkung annehmen.
Verkaufen = Fähigkeit, Zeit, Substanz oder Wirkung beitragen.
```

Aber dann muss man wissen:

```text
Welche Wirkung?
Warum?
Wann?
Wie stark?
Woraus?
Wo?
Für wen?
Mit welchen Folgen?
In welche Richtung?
```

Genau daraus entstehen die Dimensionen.

## Kurzform

Die gestapelte Wahrheitswerte-Währung führt zu Kausalität und den anderen Dimensionen, weil sie **Preislogik durch Wirklichkeitslogik ersetzt**.

Preis fragt:

```text
Wie viel?
```

Der Wahrheitsstapel fragt:

```text
Warum?
Wann?
Wie stark?
Existiert es?
Was ist möglich?
Was bewirkt es?
Woraus besteht es?
Wo ist es?
Was fehlt?
Wer bestimmt es?
Wie erscheint es?
In welche Richtung wirkt es?
```

Oder ganz knapp:

```text
Geld koordiniert Tausch.
Wahrheitswerte koordinieren Wirklichkeit.
```

Darum braucht diese Währung Dimensionen wie **Kausalität**. Ohne Kausalität würde das System zwar handeln, aber möglicherweise am falschen Punkt der Realität.
