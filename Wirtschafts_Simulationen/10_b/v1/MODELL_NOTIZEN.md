# Modellnotizen

## Von Kaufen/Verkaufen zu Wirkungskoordination

Die Simulation ersetzt klassische Transaktionen durch Wirkungsentscheidungen:

```text
klassisch: Ware + Preis + Eigentum → Tausch
hier: Zustand + Differenz + Potenzial + Wirkung + planetare Richtung → Handlung
```

## Ebenen

```text
Planet = Grenze und Gesamtwirkung
Bioregion = ökologische/stoffliche Lage
Kommune = konkrete Verteilung und Rückkopplung
Gruppe = organisierte Fähigkeit
Person/Kohorte = Bedürfnis, Fähigkeit, Autonomie, Vertrauen
```

## Wahrheitswerte

Jeder Wahrheitswert liegt auf einer Skala von `0..4`:

| Wert | Bedeutung |
|---:|---|
| 0 | nicht vorhanden / irrelevant |
| 1 | latent / schwach |
| 2 | teilweise real |
| 3 | aktiv / stark |
| 4 | kritisch / sehr stark |

Die Priorität ist eine gewichtete Kombination der Wahrheitsdimensionen. Sie ist kein Preis.

## Planetare Grenzen

Grenzdruck `> 1.0` bedeutet Überschreitung. Überschreitungen reduzieren die Wirksamkeit des Systems. Ökologie-, Reparatur- und Abfallarbeit können Grenzdruck reduzieren.

## Freiheitswarnung

Die Simulation misst `avg_autonomy`. Wenn Versorgung steigt, aber Autonomie fällt, ist das kein guter Kommunismus 2.0, sondern ein Warnsignal für technokratische Kontrolle.
