# この惑星経済システムは全般的改善につながるのか

## 質問

この惑星経済システムは全般的改善につながるのか。

## 回答

はい。**つながる可能性があります**。しかし **自動的ではありません**。

厳しい答えは次のとおりです。

```text
このシステムが世界を改善するのは、真理値、データ、
意思決定、権力構造が民主的で、修正可能で、
人間的であり続ける場合だけです。
```

そうでなければ、同じ論理は管理、官僚制、強制に変わり得ます。

## なぜ改善し得るのか

このシステムは経済を次のものから移します。

```text
価値、価格、所有、利潤
```

そして次のものへ移します。

```text
必要、効果、実質、時間、潜勢力、生態的限界
```

これは強い改善です。現在の多くの問題は古い論理から生じています。有害なものが利益を生み、必要なものが利益を生まないことがあります。人々は住居、食料、医療を必要としていても、購買力がないために得られないことがあります。自然破壊は、その損害が価格に十分現れないために進みます。

このモデルの最初の問いは次のものではありません。

```text
何が利益を生むか。
```

むしろ次です。

```text
どの効果が本当に必要か。
どの差異を解決すべきか。
どの実質が存在するか。
人間と惑星にどんな結果が生じるか。
```

## 惑星にとって

自然は経済の無料の「外部」ではなくなります。気候、水、土壌、生物多様性、エネルギー、原材料、廃棄物、再生が中心的な経済条件になります。生産は生命基盤を保つ限りでのみ許容されます。

全般的改善とは、全員が常により多くの物を得ることではありません。意味するのは次です。

```text
持続可能な限界の内部で、すべての人によりよい存在条件をつくること。
```

## 個人にとって

個人にとって最大の改善は、存在不安の減少です。次の代わりに、

```text
お金が必要だ。そうでなければ住居、食料、医療、教育を得られない。
```

システムはこう問います。

```text
本当の必要は何か。
その人は何を貢献できるか。
何が発展を妨げているか。
助けるとどんな効果が生じるか。
```

これは住居、健康、食料、教育、ケア、移動、社会参加を改善し得ます。しかし危険もあります。システムが個人について知りすぎると、その人を管理できてしまいます。したがって、プライバシー、異議申し立ての権利、生活の自由、失敗する権利、常に最適化されない権利が必要です。

## 集団、コミューン、国家

集団は効果の単位になります。ケア、建設、エネルギー、農業、研究、修理、教育です。利潤をめぐって競争するのではなく、現実の差異を解決するために調整されます。

コミューンは改善が見える場所です。空き家とホームレス、食料余剰と飢餓、ケア需要とケア時間不足がそこで現れます。コミューンは予算を管理するだけでなく、現実を修正します。

国家は調整空間になります。鉄道、エネルギー、病院、水、研究、法、保護、再分配を調整します。しかし上から真理を押し付ける権力中心になってはいけません。

## 改善しない場合

次の場合には改善しません。

```text
中央機関がすべての真理を決める。
異議申し立ての権利がない。
データが操作される。
地域の知識が無視される。
すべてが最適化されるが誰も自由でない。
生態が象徴にとどまる。
官僚制が現実の効果より速く成長する。
```

その場合、それは解放の経済ではなく、美しい言葉を持つテクノクラシーです。

## 改善しやすい条件

改善しやすいのは、次の場合です。

```text
惑星の限界が拘束力を持つ。
基本的必要が贅沢に優先する。
コミューンが多くを自分で決める。
個人が権利とプライバシーを保つ。
集団が透明に働く。
国家がすべてを支配せずに調整する。
真理値が検証され修正される。
誤りが見えるようになる。
効果がイデオロギーより重要になる。
```

## 結論

はい、このシステムは全般的改善につながり得ます。しかしそれは **民主的な効果経済** としてであって、**中央集権的な真理機械** としてではありません。真の改善は、計画、誤りの修正、個人の自由、惑星の限界が一緒に働くときに生まれます。
