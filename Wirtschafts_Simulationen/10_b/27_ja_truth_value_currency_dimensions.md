# なぜ積み重ねられた真理値の通貨は、因果性のような次元に至るのか

## 質問

なぜ、この積み重ねられた真理値の通貨は、たとえば **因果性** のような次元に至るのか。

## 回答

この「通貨」は **貨幣価値** を測るものではなく、**行為の真理** を測るものだからです。普通の通貨は、おおよそ次のように問います。

```text
それはいくらの価値があるのか。
誰がどれだけ支払えるのか。
どれだけ交換されるのか。
```

積み重ねられた真理値の通貨は、代わりに次のように問います。

```text
その必要は現実なのか。
原因は何か。
どれほど緊急なのか。
どれほど強いのか。
どんな手段と能力があるのか。
どんな効果が生じるのか。
行為の方向は正しいのか。
```

だから **因果性** のような次元が生まれます。経済が価格・量・所有によって調整されなくなると、システムは **なぜ** 行為するのか、そしてその行為が本当に状態の原因に触れているのかを知らなければなりません。

## 核心

このシステムでの経済行為は、主に次のものではありません。

```text
私は商品 X を価格 Y で買う。
```

むしろ次のものです。

```text
現実の状態が変化する。
```

つまり、

```text
以前の状態 → 行為 → 以後の状態
```

です。そのためには次元が必要です。すべての行為には複数の真理の問いが含まれます。たとえば飢餓は存在していても、その原因は食料不足、配分の失敗、冷蔵不足、交通の破綻、干ばつ、戦争、誤った計画、食品廃棄などさまざまです。

システムが「飢餓が高い」とだけ見れば、誤った行為をする可能性があります。**因果性** を測るなら、こう問います。

```text
この行為は飢餓の原因に触れているか。
```

因果性は、盲目的な行動主義を防ぎます。

## なぜ単一の値では足りないのか

単一の値は粗すぎます。すべてを一つの数字に押し込むと、お金と同じようなことが起きます。すべては比較可能になりますが、多くのものが見えなくなります。価格は、自然破壊、ケア労働、緊急性、本当の原因、将来の損害、地域の特殊性、権力関係を隠してしまいます。

したがって、積み重ねられた真理値は次のようなものではありません。

```text
真理 = 87 点
```

それは多次元の署名です。

```text
[因果性, 時間, 強度, 存在, 潜勢力, 効果,
 実質, 物質, 差異, 決定, 現象, 角度方向]
```

## 次元

| 次元 | なぜ必要か |
|---|---|
| 因果性 | 行為は原因に触れているのか、それとも症状だけか。 |
| 時間 | 今すぐ行動すべきか、計画できるのか。 |
| 強度 | 必要、損害、効果はどれほど強いのか。 |
| 存在 | 問題は本当に存在するのか、単なる主張なのか。 |
| 潜勢力 | どんな能力、道具、解決の道があるのか。 |
| 効果 | 行為はシステムの何を変えるのか。 |
| 実質 | どんな材料、エネルギー、食料、ケア時間、知識があるのか。 |
| 物質 | 資源とインフラは実際どこにあるのか。 |
| 差異 | 必要と現実のあいだの隙間は何か。 |
| 決定 | 行為は社会的・民主的に決定されているのか。 |
| 現象 | 状態はどのように現れ、測られ、報告されるのか。 |
| 角度方向 | 行為は再生的か、中立か、有害か、支配的か。 |

## スタックの例

```text
334434234343
```

これはお金の額ではありません。次のように読みます。

```text
因果性=3, 時間=3, 強度=4, 存在=4,
潜勢力=3, 効果=4, 実質=2, 物質=3,
差異=4, 決定=3, 現象=4, 方向=3
```

意味は、原因はかなり理解されており、状況は緊急で、現象は強く現実であり、解決可能性があり、効果は大きいが、利用可能な実質は限られている、ということです。したがって契約には条件が必要です。

## 因果性が別の次元である理由

**効果** は何が起こるかを示します。**因果性** は根源に触れているかを示します。鎮痛剤には効果があります。しかし病気の原因が汚染水なら、水を直す必要があります。

**差異** は何かが不足していることを示します。**因果性** はなぜ不足しているかを示します。飢餓は干ばつ、悪い配分、エネルギー不足、土壌破壊から来ることがあります。

**決定** は社会的正当性を示します。しかし多数派も原因を誤ることがあります。だから因果的真理と社会的決定の両方が必要です。

## 要約

お金は交換を調整します。積み重ねられた真理値は現実を調整します。だから因果性のような次元が必要です。因果性がなければ、システムは多く行動しても、現実の誤った場所で行動してしまいます。
