価値・善良度・人気度から成る貨幣は、買い角と売り角の2つの角度があるとき、どのように循環するのか？

この場合、貨幣は買い手から売り手へ流れる単純な流れではなくなる。貨幣は二重の流れとして循環する。

商品/サービスは売り手から買い手へ流れる \text{商品/サービスは売り手から買い手へ流れる}

貨幣は買い手から売り手へ流れる \text{貨幣は買い手から売り手へ流れる}

そして、その両方の流れが角度空間の中で方向を持つ。

中心となる点はこれである。

すべての取引は二重の角度交換である。 \boxed{ \text{すべての取引は二重の角度交換である。} }

買い手は単に商品を買うだけではない。
売り手も同時に、買い手の貨幣を買っている。

1. 貨幣オブジェクト

貨幣単位は価値だけではない。

M=m M = m

ではなく、次のようなものになる。

M=(m,g,b,ρ,h) M = (m,g,b,\rho,h)

ここで：

m=数値価値 m = \text{数値価値}

g=善良度 g = \text{善良度}

b=人気度 b = \text{人気度}

ρ=評価の信頼度 / 確実性 \rho = \text{評価の信頼度 / 確実性}

h=履歴 / 起源 h = \text{履歴 / 起源}

角度は善良度と人気度から得られる。

θ=atan2⁡(b,g) \theta = \operatorname{atan2}(b,g)

つまり：

g=x軸：善 vs. 悪 g = \text{x軸：善 vs. 悪}

b=y軸：人気 vs. 不人気 b = \text{y軸：人気 vs. 不人気}

貨幣の量は：

m m

方向は：

θ \theta

その方向の信頼性は：

ρ \rho

したがって、支払いは単なる：

100 100

ではなく、例えば：

100∠35∘,ρ=0.82 100 \angle 35^\circ,\quad \rho=0.82

となる。これは、100の価値単位が特定の善良度/人気度方向と特定の確実性を持つという意味である。

2. すべての主体は2つの角度を持つ

各主体 ii は以下を持つ。

θiK=買い角 \theta_i^K = \text{買い角}

θiV=売り角 \theta_i^V = \text{売り角}

最もよい定義は：

θiK=自分が受け取りたい方向 \boxed{ \theta_i^K = \text{自分が受け取りたい方向} }

θiV=自分が支出または売却したい方向 \boxed{ \theta_i^V = \text{自分が支出または売却したい方向} }

つまり：

  • 買い角は入力フィルターである。
  • 売り角は出力信号である。

これによって、各主体は角度変換器になる。

ある方向からものを受け取り、別の方向へものを出す。

θiK→θiV \theta_i^K \rightarrow \theta_i^V

もし2つの角度がほぼ同じなら、その主体は一貫している。

もし大きく離れているなら、その主体は角度変換によって稼いでいるか、そこに依存して生きている。

3. すべての取引には2つの角度チェックがある

仮に：

  • 買い手 AA が売り手 BB から買う。
  • 売り手 BB が商品またはサービスを渡す。
  • 買い手 AA が貨幣を支払う。

このとき2つの流れがある。

商品 / サービス:
B ─────────────────────────▶ A

貨幣:
A ─────────────────────────▶ B

しかし角度を入れるとこうなる。

商品流:
B は θ_B^V で売る ─────▶ A は θ_A^K で受け取る

貨幣流:
A は θ_A^V で支払う ─────▶ B は θ_B^K で受け取る

したがって、2つの角度距離が合わなければならない。

dX=d(θAK,θBV) d_X = d(\theta_A^K,\theta_B^V)

これは商品流の距離である。

そして：

dM=d(θBK,θAV) d_M = d(\theta_B^K,\theta_A^V)

これは貨幣流の距離である。

これは非常に重要である。

買い手は問う：

自分が受け取る商品は、自分の買い角に合うか？

売り手は問う：

自分が受け取る貨幣は、自分の買い角に合うか？

なぜなら売り手にとって、貨幣は受け取る財だからである。

4. 円周距離が取引可能性を決める

2つの角度の距離は：

d(α,β)=arccos⁡(cos⁡(α−β)) d(\alpha,\beta)=\arccos(\cos(\alpha-\beta))

したがって：

d∈[0,π] d \in [0,\pi]

つまり：

d=0 d=0

は完全な適合を意味する。

d=π d=\pi

は最大の対立を意味する。

単純な適合関数として：

ϕ(d)=cos⁡(d2) \phi(d)=\cos\left(\frac{d}{2}\right)

を置ける。

そのとき：

d=0⇒ϕ=1 d=0 \Rightarrow \phi=1

d=π⇒ϕ=0 d=\pi \Rightarrow \phi=0

角度が合うほど取引は強くなる。

完全な取引には両側が必要である。

Φ=ϕ(dX)⋅ϕ(dM)⋅ρX⋅ρM \Phi = \phi(d_X)\cdot \phi(d_M)\cdot \rho_X \cdot \rho_M

ここで：

dX=商品の角度距離 d_X = \text{商品の角度距離}

dM=貨幣の角度距離 d_M = \text{貨幣の角度距離}

ρX=商品角の信頼度 \rho_X = \text{商品角の信頼度}

ρM=貨幣角の信頼度 \rho_M = \text{貨幣角の信頼度}

Φ\Phi が高ければ、貨幣は容易に循環する。

Φ\Phi が低ければ、値引き、手数料、保険、監査、回転、あるいは取引不成立が起こる。

5. 取引の流れ

完全な取引は次のように進む。

ステップ1：買い手が需要を生む

買い手 AA は言う：

私は θAK に近い方向の財が欲しい \text{私は } \theta_A^K \text{ に近い方向の財が欲しい}

例えば：

θAK=30∘ \theta_A^K = 30^\circ

これは、買い手が善良で、ある程度人気のあるものを求めているという意味である。

ステップ2：売り手が提示する

売り手 BB は言う：

私は θBV の方向を持つ財を売る \text{私は } \theta_B^V \text{ の方向を持つ財を売る}

例えば：

θBV=55∘ \theta_B^V = 55^\circ

このとき商品距離は：

dX=25∘ d_X = 25^\circ

比較的近い。買い手はおそらく受け入れる。

ステップ3：買い手が支払いを提示する

買い手 AA は中立的な貨幣で支払うのではなく、自分の出力角の貨幣で支払う。

θAV \theta_A^V

例えば：

θAV=80∘ \theta_A^V = 80^\circ

その貨幣は非常に人気があるかもしれないが、善良度は中程度かもしれない。

ステップ4：売り手が支払いを確認する

売り手 BB は、入ってくる価値に対して買い角を持つ。

θBK \theta_B^K

例えば：

θBK=70∘ \theta_B^K = 70^\circ

このとき貨幣距離は：

dM=10∘ d_M = 10^\circ

この貨幣は売り手によく合う。

ステップ5：取引が実行される

両方の距離が十分小さいなら：

dX≤εX d_X \leq \varepsilon_X

dM≤εM d_M \leq \varepsilon_M

取引が行われる。

買い手は商品を得る。

売り手は貨幣を得る。

しかし両者が得るのは価値だけではなく、角度品質でもある。

6. 実際に循環するものは何か？

同時に3つのものが循環する。

価値 \boxed{ \text{価値} }

善良度 \boxed{ \text{善良度} }

人気度 \boxed{ \text{人気度} }

ただし、それらは同じようには循環しない。

価値は支払いによって循環する

A→B A \rightarrow B

買い手は数値価値を失う。

売り手は数値価値を得る。

善良度は起源・生産・評価によって循環する

善良度は実際の行為によって生じたり消えたりする。

  • 清潔なサプライチェーン
  • 公正な労働
  • 低い害
  • 良い製品
  • 損害の修復
  • 合法性
  • 環境影響
  • 社会的影響
  • 透明性
  • 監査
  • 裁判所
  • 政府評価

したがって善良度は単なる意見ではない。実際の結果と制度的審査により強く結びついている。

人気度は受容と注意によって循環する

人気度は次のものから生じる。

  • 需要
  • 顧客満足
  • メディア
  • トレンド
  • 広告
  • ソーシャルネットワーク
  • 文化的象徴
  • 政治陣営
  • ボイコット
  • 抗議
  • インフルエンサー
  • 群集行動

人気度は善良度より速く動く。

だから人気度は速く上がり、速く崩れることもある。

7. 買い手側のバランス変化

購入前、買い手 AA は次を持つ。

MA=(mA,gA,bA) M_A = (m_A,g_A,b_A)

彼は支払う。

ΔM=(p,gpay,bpay) \Delta M = (p,g_{\text{pay}},b_{\text{pay}})

すると貨幣残高は下がる。

mA′=mA−p m_A' = m_A - p

彼が出す貨幣の方向は：

θAV \theta_A^V

同時に彼は商品を得る。

X=(u,gX,bX) X = (u,g_X,b_X)

ここで uu は効用、gXg_X は善良度、bXb_X は人気度である。

商品が消費されると、それは単に貨幣になるのではない。次を変える。

  • 効用
  • 生活水準
  • 評判
  • 将来の選好
  • 政治的意見
  • 需要
  • 場合によっては自身の生産性

家計の場合：

商品→効用 / 満足 / 意見 \text{商品} \rightarrow \text{効用 / 満足 / 意見}

企業の場合：

商品→input / サプライチェーン / 新しい生産角 \text{商品} \rightarrow \text{input / サプライチェーン / 新しい生産角}

これは重要である。企業が悪い input を買うと、その悪い角度が後で自社製品に入る可能性がある。

8. 売り手側のバランス変化

売り手 BB は商品を渡す。

XB=(u,gX,bX) X_B = (u,g_X,b_X)

そして貨幣を受け取る。

Min=(p,gM,bM) M_{\text{in}} = (p,g_M,b_M)

貨幣残高は増える。

mB′=mB+p m_B' = m_B + p

しかし貨幣の質も変わる。

gB′=gB+gM g_B' = g_B + g_M

bB′=bB+bM b_B' = b_B + b_M

新しい現金角は：

θBcash=atan2⁡(bB′,gB′) \theta_B^{\text{cash}}= \operatorname{atan2}(b_B',g_B')

多くの顧客が善良で人気のある貨幣で支払えば、企業の現金はその方向へ引かれる。

多くの顧客が有毒な貨幣で支払えば、企業の現金は汚染される。

つまり：

起源を持つのは商品だけではない。顧客の貨幣も起源を持つ。 \boxed{ \text{起源を持つのは商品だけではない。顧客の貨幣も起源を持つ。} }

9. ベクトル財布：貨幣は束として管理される

実際には、主体は財布を単なる合計として保存すべきではない。

多くの貨幣ロットを持つ。

Mi={Mi1,Mi2,Mi3,...} M_i = \{M_{i1},M_{i2},M_{i3},...\}

各ロットには：

(m,g,b,ρ,h) (m,g,b,\rho,h)

がある。

例えば：

ロット1: 500価値、良い角度、高信頼度
ロット2: 200価値、人気だが疑わしい
ロット3: 100価値、有毒、低信頼度

主体が支払うとき、どの貨幣を出すかを選ぶ。

これはコイン選択である。

可能な戦略：

最良の貨幣から使う

より良い価格を得るために、良い貨幣で支払う。

最悪の貨幣から使う

有毒な貨幣を手放そうとする。

適合する貨幣から使う

売り手の買い角に合うロットを探す。

偽装混合

悪い貨幣を良い貨幣と混ぜて、受け入れ可能な平均角を作る。

ここで角度ロンダリングが生まれる。

10. 売り手は支払いを拒否できる

売り手はすべての貨幣を同じように受け入れるわけではない。

売り手は確認する。

dM=d(θBK,θAV) d_M = d(\theta_B^K,\theta_A^V)

もし貨幣が買い角から遠すぎるなら、いくつかの可能性がある。

拒否

dM>ε⇒取引なし d_M > \varepsilon \Rightarrow \text{取引なし}

割引

売り手は貨幣を受け入れるが、価値を割り引いて数える。

meff=m⋅ϕ(dM) m_{\text{eff}} = m \cdot \phi(d_M)

例えば：

100∠160∘ 100 \angle 160^\circ

は、彼にとっては：

62 62

としてしか数えられないかもしれない。

追加料金

買い手はより多く支払う必要がある。

prequired=pϕ(dM) p_{\text{required}} = \frac{p}{\phi(d_M)}

回転

角度トレーダーまたは銀行が手数料を取って貨幣を回転させる。

θAV→θBK \theta_A^V \rightarrow \theta_B^K

そのコストは：

Crot=λmtan⁡2(dM2) C_{\text{rot}}=\lambda m \tan^2\left(\frac{d_M}{2}\right)

角度距離が大きいほど、回転は高くつく。

監査

起源を確認する。悪い角度が誤情報に基づいているなら、信頼度または方向を修正できる。

11. 買い手は商品を拒否できる

同時に買い手は確認する。

dX=d(θAK,θBV) d_X = d(\theta_A^K,\theta_B^V)

商品が希望する買い角から遠すぎる場合：

買わない

商品は売れ残る。

値下げ

売り手は安くしなければならない。

商品改善

売り手は実際の改善に投資する。

価値→善良度 \text{価値} \rightarrow \text{善良度}

マーケティング

売り手は認知に投資する。

価値→人気度 \text{価値} \rightarrow \text{人気度}

認証

売り手は角度をより信頼できるものにする。

ρ↑ \rho \uparrow

つまり、商品角は販売能力を決める。

貨幣角は支払い能力を決める。

12. 2つの角度は各取引に4つの役割を作る

各取引には4つの重要な角度がある。

θAK=買い手が商品を受け取る \theta_A^K = \text{買い手が商品を受け取る}

θAV=買い手が貨幣を渡す \theta_A^V = \text{買い手が貨幣を渡す}

θBK=売り手が貨幣を受け取る \theta_B^K = \text{売り手が貨幣を受け取る}

θBV=売り手が商品を渡す \theta_B^V = \text{売り手が商品を渡す}

そこから2つのマッチングが生じる。

θAK↔θBV \theta_A^K \leftrightarrow \theta_B^V

これは商品用である。

θBK↔θAV \theta_B^K \leftrightarrow \theta_A^V

これは貨幣用である。

これが完全な循環メカニズムである。

                 商品角
          θ_B^V ───────────────▶ θ_A^K
          売り手                  買い手


                   貨幣角
          θ_B^K ◀─────────────── θ_A^V
          売り手                  買い手

両方の接続が短いと取引は安定する。

片方が短く、もう片方が長いと取引は不安定になる。

13. 例：良い取引

買い手 AA：

θAK=40∘ \theta_A^K = 40^\circ

θAV=60∘ \theta_A^V = 60^\circ

売り手 BB：

θBK=55∘ \theta_B^K = 55^\circ

θBV=45∘ \theta_B^V = 45^\circ

すると：

dX=d(40∘,45∘)=5∘ d_X = d(40^\circ,45^\circ)=5^\circ

dM=d(55∘,60∘)=5∘ d_M = d(55^\circ,60^\circ)=5^\circ

両側が合っている。

商品は買い手に合っている。

貨幣は売り手に合っている。

取引は非常に流動的である。

Φ≈1 \Phi \approx 1

貨幣は容易に循環する。

14. 例：商品は合うが貨幣は合わない

買い手 AA：

θAK=40∘ \theta_A^K = 40^\circ

θAV=150∘ \theta_A^V = 150^\circ

売り手 BB：

θBK=50∘ \theta_B^K = 50^\circ

θBV=45∘ \theta_B^V = 45^\circ

すると：

dX=d(40∘,45∘)=5∘ d_X = d(40^\circ,45^\circ)=5^\circ

商品は合う。

しかし：

dM=d(50∘,150∘)=100∘ d_M = d(50^\circ,150^\circ)=100^\circ

貨幣が合わない。

結果：

  • 買い手は買いたい。
  • 売り手は売りたい。
  • しかし売り手は貨幣を信用しない。
  • 追加料金、回転、監査、または別の貨幣が必要になる。

これは購買力があるのに支払い問題がある状態に似ている。

買い手には価値があるが、角度が間違っている。

15. 例：貨幣は合うが商品は合わない

買い手 AA：

θAK=30∘ \theta_A^K = 30^\circ

θAV=60∘ \theta_A^V = 60^\circ

売り手 BB：

θBK=55∘ \theta_B^K = 55^\circ

θBV=150∘ \theta_B^V = 150^\circ

すると：

dM=d(55∘,60∘)=5∘ d_M = d(55^\circ,60^\circ)=5^\circ

貨幣は合う。

しかし：

dX=d(30∘,150∘)=120∘ d_X = d(30^\circ,150^\circ)=120^\circ

結果：

  • 売り手は喜んで貨幣を受け取るだろう。
  • 買い手はその方向の商品を欲しない。
  • 売り手は改善するか、安くするか、別の買い手層を見つける必要がある。

これは支払い能力のある顧客がいるのに販売問題が起きる状態である。

16. 例：両方向とも合わない

買い手 AA：

売り手 BB：

17. 循環は変換連鎖である

各主体は、自分の買い角に近い入力価値を受け取る。

θK \theta^K

そして、自分の売り角に近い出力価値を出す。

θV \theta^V

したがって各主体は経済的な角度変換器である。

Ti:(m,g,b)in→(m′,g′,b′)out T_i: (m,g,b)_{\text{in}} \rightarrow (m',g',b')_{\text{out}}

または：

θiK→θiV \theta_i^K \rightarrow \theta_i^V

例：

企業

inputs と労働を買う。

θ企業K \theta^K_{\text{企業}}

商品を生産する。

θ企業V \theta^V_{\text{企業}}

実際の品質を生むなら：

g↑ g \uparrow

良い広告を行うなら：

b↑ b \uparrow

害を外部化するなら：

g↓ g \downarrow

害があっても人気を保つなら：

b↑,g↓ b \uparrow,\quad g \downarrow

家計

賃金を受け取る。

θ家計K \theta^K_{\text{家計}}

消費貨幣を支出する。

θ家計V \theta^V_{\text{家計}}

その購買判断が企業の人気を変える。

銀行

預金を受け取る。

θ銀行K \theta^K_{\text{銀行}}

融資を出す。

θ銀行V \theta^V_{\text{銀行}}

借り手、目的、リスクに応じた角度を持つ新しい貨幣を作る。

政府

税を受け取る。

θ国家K \theta^K_{\text{国家}}

公共支出を行う。

θ国家V \theta^V_{\text{国家}}

法律によって善良度を定義し、支出によって角度を動かせる。

メディア

注意と金を受け取る。

θメディアK \theta^K_{\text{メディア}}

人気または不人気を出力する。

θメディアV \theta^V_{\text{メディア}}

主に bb、つまり人気度に影響する。

裁判所 / 監査

案件、証拠、手数料を受け取る。

θ裁判所/監査K \theta^K_{\text{裁判所/監査}}

信頼度と善良度の修正を出す。

θ裁判所/監査V \theta^V_{\text{裁判所/監査}}

主に gg と ρ\rho に影響する。

18. 最も重要な循環公式

買い手 AA と売り手 BB の取引では：

dX=d(θAK,θBV) d_X = d(\theta_A^K,\theta_B^V)

dM=d(θBK,θAV) d_M = d(\theta_B^K,\theta_A^V)

そのとき：

取引量=Q⋅ϕ(dX)⋅ϕ(dM)⋅ρX⋅ρM \text{取引量} = Q \cdot \phi(d_X)\cdot \phi(d_M)\cdot \rho_X\cdot\rho_M

または簡潔に：

QT=Q0Φ Q_T = Q_0 \Phi

ここで：

Φ=ϕ(dX)ϕ(dM)ρXρM \Phi = \phi(d_X)\phi(d_M)\rho_X\rho_M

Φ\Phi が高ければ、多くが循環する。

Φ\Phi が低ければ、少ししか循環しない。

多くの主体の買い角と売り角が不一致なら、経済全体の流動性は下がる。

19. 価値はどのように善良度を買うか

価値は善良度を買える。ただし実際の変化を通じてのみである。

例えば：

価値→より良い労働条件 \text{価値} \rightarrow \text{より良い労働条件}

価値→クリーンエネルギー \text{価値} \rightarrow \text{クリーンエネルギー}

価値→損害賠償 \text{価値} \rightarrow \text{損害賠償}

価値→製品安全 \text{価値} \rightarrow \text{製品安全}

価値→サプライチェーン検査 \text{価値} \rightarrow \text{サプライチェーン検査}

すると：

g↑ g \uparrow

可能なシミュレーション規則：

Δg=ηg⋅log⁡(1+Ig)⋅Rreal⋅ρaudit \Delta g = \eta_g \cdot \log(1+I_g)\cdot R_{\text{real}}\cdot \rho_{\text{audit}}

ここで：

Ig=実際の改善への投資 I_g = \text{実際の改善への投資}

Rreal=現実因子 R_{\text{real}} = \text{現実因子}

ρaudit=監査信頼度 \rho_{\text{audit}} = \text{監査信頼度}

企業が良いと主張するだけで実際の改善をしないなら：

Rreal≈0 R_{\text{real}} \approx 0

短期的に人気は上がるかもしれないが、実際の善良度は上がらない。

20. 価値はどのように人気度を買うか

価値は人気度をより簡単に買える。

価値→広告 \text{価値} \rightarrow \text{広告}

価値→割引 \text{価値} \rightarrow \text{割引}

価値→インフルエンサー \text{価値} \rightarrow \text{インフルエンサー}

価値→メディアキャンペーン \text{価値} \rightarrow \text{メディアキャンペーン}

価値→スポンサー \text{価値} \rightarrow \text{スポンサー}

すると：

b↑ b \uparrow

可能なシミュレーション規則：

Δb=ηb⋅log⁡(1+Ib)⋅Mmedia⋅Strend−Bbacklash \Delta b = \eta_b \cdot \log(1+I_b)\cdot M_{\text{media}}\cdot S_{\text{trend}} - B_{\text{backlash}}

ここで：

Ib=広告 / PR支出 I_b = \text{広告 / PR支出}

Mmedia=メディア増幅 M_{\text{media}} = \text{メディア増幅}

Strend=トレンド因子 S_{\text{trend}} = \text{トレンド因子}

Bbacklash=反発 B_{\text{backlash}} = \text{反発}

人気度は善良度より速いが、不安定でもある。

したがってしばしば：

b↑,g は同じまま b \uparrow,\quad g \text{ は同じまま}

あるいは：

b↑,g↓ b \uparrow,\quad g \downarrow

が起きる。

これは：

人気だが悪い \text{人気だが悪い}

という場合である。

21. 人気度はどのように善良度を買えるか

人気度は善良度を直接買えないが、改革を容易にできる。

人気企業には：

  • より多くの顧客信頼
  • より多くの政治資本
  • 従業員へのアクセスのしやすさ
  • 投資家の忍耐
  • 高い価格決定力
  • 変化への抵抗の少なさ

がある。

そのため人気度を実際の改革能力へ変換できる。

b→g b \rightarrow g

例えば：

Δg=ηbg⋅b⋅Ig⋅ρ \Delta g = \eta_{bg}\cdot b \cdot I_g \cdot \rho

ただしここでも実際の投資が必要である。

人気度だけでは善良度ではない。

それは善良度を作りやすくする資源でしかない。

22. 善良度はどのように人気度を買えるか

善良度は人気度を生み出せる。ただし見えるようになった場合だけである。

g→b g \rightarrow b

これには次が必要である。

  • 透明性
  • 自由なメディア
  • 信頼できる監査
  • 分かりやすいコミュニケーション
  • 教育
  • 時間
  • 信頼

可能な規則：

Δb=ηgb⋅g⋅Tvisibility⋅ρ \Delta b = \eta_{gb}\cdot g \cdot T_{\text{visibility}}\cdot \rho

ここで：

Tvisibility=可視性 T_{\text{visibility}} = \text{可視性}

誰も善良度を見なければ、人気度はほとんど上がらない。

したがって、善良だが見えない企業は不人気のままであり得る。

23. 危険な循環：角度ロンダリング

角度ロンダリングは、誰かが悪い価値をより良く見える角度に変えるときに生じる。

例えば：

1000∠160∘→900∠40∘ 1000 \angle 160^\circ \rightarrow 900 \angle 40^\circ

しかし実際の改善はない。

これは次によって起こり得る。

  • 子会社
  • 仲介業者
  • 偽監査
  • PRキャンペーン
  • 寄付
  • 買われた格付け
  • 人工的な人気
  • ボットネットワーク
  • 税と角度の避難地

すると見かけ上は：

g↑,b↑ g \uparrow,\quad b \uparrow

となるが、信頼度は下がるべきである。

ρ↓ \rho \downarrow

そして履歴 hh は疑わしくなるべきである。

だからシステムには起源の痕跡が必要である。

h=取引履歴 h = \text{取引履歴}

履歴がなければ、角度貨幣は洗浄可能になる。

24. 労働市場での循環

労働市場は特に重要である。

企業は労働を買う。

労働者は労働を売る。

企業にとって労働は input である。

θ企業K \theta_{\text{企業}}^K

労働者にとって賃金は入ってくる価値である。

θ労働者K \theta_{\text{労働者}}^K

同時に：

  • 労働者は自分の売り角で労働力を売る。
  • 企業は自分の売り角で賃金を払う。

したがって再び2つのマッチングがある。

d労働=d(θ企業K,θ労働者V) d_{\text{労働}} = d(\theta_{\text{企業}}^K,\theta_{\text{労働者}}^V)

d賃金=d(θ労働者K,θ企業V) d_{\text{賃金}} = d(\theta_{\text{労働者}}^K,\theta_{\text{企業}}^V)

労働は合うが賃金角が悪い場合、労働者はより高い賃金を求める。

賃金は良いが活動が悪い場合、労働者はそれでも拒否できる。

これは実際の例を説明する。

高賃金、悪い雇用主 \text{高賃金、悪い雇用主}

低賃金、良い目的 \text{低賃金、良い目的}

人気企業、悪い労働条件 \text{人気企業、悪い労働条件}

不人気な職業、高い社会的価値 \text{不人気な職業、高い社会的価値}

25. 信用市場での循環

信用では、貨幣が新たに作られるか、時間の中で移動する。

銀行は信用を出す。

θ銀行V \theta_{\text{銀行}}^V

債務者は信用を受け取る。

θ債務者K \theta_{\text{債務者}}^K

後に債務者は返済する。

θ債務者V \theta_{\text{債務者}}^V

銀行は返済を受け取る。

θ銀行K \theta_{\text{銀行}}^K

したがって：

d信用=d(θ債務者K,θ銀行V) d_{\text{信用}}=d(\theta_{\text{債務者}}^K,\theta_{\text{銀行}}^V)

d返済=d(θ銀行K,θ債務者V) d_{\text{返済}}=d(\theta_{\text{銀行}}^K,\theta_{\text{債務者}}^V)

信用が良い目的に使われるなら：

g信用↑ g_{\text{信用}} \uparrow

人気の投機を融資するなら：

b信用↑,g信用 は不確実 b_{\text{信用}} \uparrow,\quad g_{\text{信用}} \text{ は不確実}

有毒な活動を融資するなら：

g信用↓ g_{\text{信用}} \downarrow

すると金利または担保が上がる。

金利は次から成る。

i=i0+iデフォルト+i角度リスク+iρ i = i_0 + i_{\text{デフォルト}} + i_{\text{角度リスク}} + i_{\rho}

つまり：

金利=時間価格+リスク+角度罰則 \text{金利} = \text{時間価格} + \text{リスク} + \text{角度罰則}

26. 国家での循環

国家は税を受け取る。

θ国家K \theta_{\text{国家}}^K

そして公共支出を行う。

θ国家V \theta_{\text{国家}}^V

有毒な源泉からの税は問題になり得る。

国家は悪い貨幣を受け入れるべきか？ \text{国家は悪い貨幣を受け入れるべきか？}

受け入れるなら、それを浄化する必要があるかもしれない。

θ有毒→θ公的に正当 \theta_{\text{有毒}} \rightarrow \theta_{\text{公的に正当}}

その手段は：

  • 裁判所
  • 透明性
  • 再分配
  • 損害修復
  • 公共投資

公共支出は新しい角度を作る。

  • 教育は gg を高める。
  • プロパガンダは bb を人工的に高める。
  • インフラは価値と善良度を高める。
  • 抑圧は短期の秩序を作れるが、長期的には悪い角度を生む。
  • 戦争は国民と政府によって非常に異なる角度を持ち得る。

したがって国家は巨大な角度変換器である。

27. 国家間の循環

各国には独自の軸がある。

A国で良いものが、B国でも良いとは限らない。

したがって角度翻訳が必要である。

TA→B(θ) T_{A\rightarrow B}(\theta)

輸出取引では：

θ輸出, A→TA→B(θ輸出, A) \theta_{\text{輸出, A}} \rightarrow T_{A\rightarrow B}(\theta_{\text{輸出, A}})

例えば：

40∘ in A国 40^\circ \text{ in A国}

が：

110∘ in B国 110^\circ \text{ in B国}

になることがある。

すると国際的な角度アービトラージが生じる。

企業は次のような国を探す。

  • 自社製品がより人気である
  • 自社の善良度がより良く評価される
  • 悪い影響がより見えにくい
  • 履歴がより緩く検査される

これは道徳的な立地アービトラージである。

28. 複数市場では何が起きるか？

各市場には独自の角度構造がある。

商品市場

θ買い手K↔θ売り手V \theta_{\text{買い手}}^K \leftrightarrow \theta_{\text{売り手}}^V

支払い市場

θ売り手K↔θ買い手V \theta_{\text{売り手}}^K \leftrightarrow \theta_{\text{買い手}}^V

労働市場

θ企業K↔θ労働者V \theta_{\text{企業}}^K \leftrightarrow \theta_{\text{労働者}}^V

そして：

θ労働者K↔θ企業V \theta_{\text{労働者}}^K \leftrightarrow \theta_{\text{企業}}^V

信用市場

θ債務者K↔θ銀行V \theta_{\text{債務者}}^K \leftrightarrow \theta_{\text{銀行}}^V

後には：

θ銀行K↔θ債務者V \theta_{\text{銀行}}^K \leftrightarrow \theta_{\text{債務者}}^V

資本市場

投資家は企業持分を買う。

θ投資家K↔θ企業V \theta_{\text{投資家}}^K \leftrightarrow \theta_{\text{企業}}^V

企業は資本を買う。

θ企業K↔θ投資家V \theta_{\text{企業}}^K \leftrightarrow \theta_{\text{投資家}}^V

角度市場

ここでは方向が直接取引される。

(m,g,b)→(m′,g′,b′) (m,g,b) \rightarrow (m',g',b')

手数料、リスク、信頼度損失を伴う。

29. 2つの角度の経済的意味

買い角と売り角の差が、事業ロジックの核心である。

si=d(θiK,θiV) s_i = d(\theta_i^K,\theta_i^V)

これが主体の角度スプレッドである。

小さいスプレッド

si≈0 s_i \approx 0

主体は似た方向で買い、似た方向で売る。

これは：

  • 一貫している
  • 信頼できる
  • 変換作業が少ない
  • アービトラージが少ない
  • 信用度が高い

ことを意味する。

大きいスプレッド

si≫0 s_i \gg 0

主体は一方向で買い、別方向で売る。

これは良い場合も悪い場合もある。

良い場合

悪い inputs を買って本当に改善する。

θK=悪い \theta^K = \text{悪い}

θV=良い \theta^V = \text{良い}

その場合、実際の価値改善を作る。

悪い場合

悪い inputs を買い、良い包装だけで売る。

θK=悪い \theta^K = \text{悪い}

θV=見かけ上良い \theta^V = \text{見かけ上良い}

その場合、角度ロンダリングである。

搾取的な場合

良い inputs を買い、悪い outputs を売る。

θK=良い \theta^K = \text{良い}

θV=悪い \theta^V = \text{悪い}

その場合、善良度または信頼を破壊する。

30. 経済全体の循環

経済全体は次のようになる。

家計
  │ 商品を買う
  ▼
企業
  │ 賃金を払い、inputs を買い、融資を受ける
  ▼
銀行 / 資本市場
  │ 企業と国家を金融する
  ▼
国家
  │ 課税し、規制し、補助する
  ▼
メディア / 国民 / 裁判所 / 政府
  │ 善良度、人気度、信頼度を評価する
  ▼
角度市場
  │ 方向を回転し、保険をかけ、監査し、取引する
  ▼
家計と企業

価値は支払いによって流れる。

善良度は実際の結果と制度的判断によって流れる。

人気度は需要、メディア、社会的受容によって流れる。

信頼度は証拠、透明性、争いによって流れる。

履歴は取引連鎖を通じて流れる。

31. 貨幣循環は選択的になる

通常の貨幣では：

100=100 100 = 100

あなたのシステムでは：

100∠30∘≠100∠150∘ 100 \angle 30^\circ \neq 100 \angle 150^\circ

したがって貨幣はどこでも同じようには循環しない。

ゾーンが形成される。

清潔な高信頼循環

良い貨幣が信頼できる主体の間で循環する。

g↑,b↑,ρ↑ g \uparrow,\quad b \uparrow,\quad \rho \uparrow

そこでは金利が低く、取引が速く、スプレッドが小さい。

人気だが疑わしい循環

人気の貨幣は速く循環するが、リスクがある。

b↑,g は不確実 b \uparrow,\quad g \text{ は不確実}

そこにはバブルとスキャンダルがある。

善良だが不人気な循環

善良だが不人気な活動には、忍耐、補助金、教育が必要である。

g↑,b↓ g \uparrow,\quad b \downarrow

そこでは資金不足の危険がある。

有毒循環

悪い貨幣は影の市場、または大幅な割引で循環する。

g↓,b↓,ρ↓ g \downarrow,\quad b \downarrow,\quad \rho \downarrow

そこでは金利が高く、詐欺が多く、流動性が低い。

32. なぜ循環は自動的に道徳的にならないのか

よくある誤りは：

善良度と人気度が貨幣に入れば、経済は自動的に良くなる。

という考えである。

そうではない。

このシステムは道徳的方向を取引可能にする。

したがって操作可能にもする。

結果として3つの形が生じ得る。

実際の改善

価値→実際の善良度 \text{価値} \rightarrow \text{実際の善良度}

象徴的改善

価値→人気度 \text{価値} \rightarrow \text{人気度}

詐欺的改善

価値→見かけ上の善良度 \text{価値} \rightarrow \text{見かけ上の善良度}

だから ρ\rho、つまり信頼度が絶対に中心である。

信頼度がなければ、角度はプロパガンダのラベルになる。

信頼度があれば、角度は検証可能になる。

33. 最も短いメカニズム

最短の完全な説明は：

主体は買い角を通じて受け取り、売り角を通じて送り出す。 \boxed{ \text{主体は買い角を通じて受け取り、売り角を通じて送り出す。} }

各取引は確認する。

商品の売り角は買い手の買い角に合うか？ \boxed{ \text{商品の売り角は買い手の買い角に合うか？} }

そして：

貨幣の売り角は売り手の買い角に合うか？ \boxed{ \text{貨幣の売り角は売り手の買い角に合うか？} }

合うなら、価値、善良度、人気度は容易に流れる。

合わないなら、次が生じる。

  • 割引
  • 追加料金
  • 回転
  • 監査費用
  • 保険
  • 待ち時間
  • 影の市場
  • 評判リスク
  • 政治的対立

貨幣循環はもはや円ではなく、有向ネットワークである。

価値は適合する角度に沿って流れる。 \boxed{ \text{価値は適合する角度に沿って流れる。} }

善良度は実際の改善と承認に沿って流れる。 \boxed{ \text{善良度は実際の改善と承認に沿って流れる。} }

人気度は注意と賛同に沿って流れる。 \boxed{ \text{人気度は注意と賛同に沿って流れる。} }

各主体の2つの角度が、その主体が何を吸収したいか、そして世界へ何を出すかを決める。

そこから経済ダイナミクスが生まれる。
