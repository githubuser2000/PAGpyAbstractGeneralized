シミュレーションからの結論：価値・善性・人気を持つ経済

シミュレーションとモデルの論理から、まず最も重要な結論が出る。

角度そのものが生産要素になる。 \boxed{ \text{角度そのものが生産要素になる。} }

重要なのは資本、労働、土地、技術、知識だけではなくなる。さらに次のものが加わる。

方向づけられた正統性=(善性,人気,信頼度) \text{方向づけられた正統性} = (\text{善性}, \text{人気}, \text{信頼度})

したがって、このシステムは単に「より道徳的なお金」を作るわけではない。通常の経済の上に、第二の経済を作る。信頼、善性、人気、角度翻訳、角度回転、正統性アービトラージの経済である。

通常の経済は残る。

製品+サービス+労働+信用+資本 \text{製品} + \text{サービス} + \text{労働} + \text{信用} + \text{資本}

しかしその上に追加の層が乗る。

角度市場+オラクル+監査+評判+政治的受容 \text{角度市場} + \text{オラクル} + \text{監査} + \text{評判} + \text{政治的受容}

結果は 正統性経済 である。

1. お金はスカラーから社会的ベクトルになる

通常のお金は：

m m

あなたのお金は：

M=(m,θ,ρ,h) M = (m,\theta,\rho,h)

ここで：

m=数値価値 m = \text{数値価値}

θ=善性と人気からなる角度 \theta = \text{善性と人気からなる角度}

ρ=信頼度 / 判断の確かさ \rho = \text{信頼度 / 判断の確かさ}

h=由来 / 履歴 h = \text{由来 / 履歴}

これにより、お金は中立ではなくなる。すべての貨幣単位が一つの主張を持つ。

このお金は特定の方向から来て、特定の行為によって生まれ、特定の制度に評価され、特定の集団に受け入れられたり拒否されたりする。

これはすべてを変える。主体は単により多くのお金を争うのではなく、より良い方向を持つお金を争う。

企業は数値上は豊かでも、悪い角度のお金を持っていることがある。

m↑,θ=有毒,ρ↓ m \uparrow,\quad \theta = \text{有毒},\quad \rho \downarrow

逆に、資金は少なくても非常に高品質な角度のお金を持つこともある。

m↓,θ=善い/人気,ρ↑ m \downarrow,\quad \theta = \text{善い/人気},\quad \rho \uparrow

これは古典的資本主義からの大きな断絶である。

2. すべての価格は三つの価格に分裂する

このようなシステムでは、すべての財はもはや一つの価格だけを持たない。

少なくとも三つの価格を持つ。

数値価格 \text{数値価格}

角度価格 \text{角度価格}

信頼度価格 \text{信頼度価格}

つまり：

P=(p,θ,ρ) P = (p,\theta,\rho)

ある製品は安くても、角度が悪いかもしれない。その場合、それは本当に安いわけではない。買い手が角度コストを負うからである。

ある製品は高くても、角度が良いかもしれない。その場合でも魅力的でありうる。買い手は清潔で、受容され、評判の強いお金や地位を得るからである。

実効価値はおおよそ次のようになる。

Weff=m⋅ρ⋅q(d) W_{\text{eff}} = m \cdot \rho \cdot q(d)

ここで：

d=買い手と売り手の角度距離 d = \text{買い手と売り手の角度距離}

そして q(d)q(d) は互換性関数であり、たとえば：

q(d)=cos⁡(d2) q(d)=\cos\left(\frac{d}{2}\right)

これは次を意味する。

d=0⇒完全に取引可能 d=0 \Rightarrow \text{完全に取引可能}

d=π⇒最大の遮断 d=\pi \Rightarrow \text{最大の遮断}

したがって、取引はお金が足りないからだけではなく、方向が間違っているからも失敗する。

3. 各主体の二つの角度が新しい bid-ask spread を作る

すべての主体は持つ。

θK=買い角度 \theta_K = \text{買い角度}

θV=売り角度 \theta_V = \text{売り角度}

買い角度は言う。
私はどのような価値を受け入れる用意があるのか。

売り角度は言う。
私はどのような価値を渡したい、または外向きに示したいのか。

その間に角度スプレッドが生まれる。

s=d(θK,θV) s = d(\theta_K,\theta_V)

これは通常取引の価格スプレッドに似ている。

bid-ask spread \text{bid-ask spread}

ただしここでは道徳的・社会的スプレッドである。

小さいスプレッドは：

高い一貫性、高い流動性、少ない不信 \text{高い一貫性、高い流動性、少ない不信}

大きいスプレッドは：

矛盾、不信、機会主義、または戦略的偽装 \text{矛盾、不信、機会主義、または戦略的偽装}

例：

ある企業が悪い角度で安く汚い投入財を買い、良いマーケティング角度で製品を売る。このとき：

θK≠θV \theta_K \neq \theta_V

システムは認識する。この企業は角度差で生きている。

ここから新しい市場が生まれる。

角度マーケットメイキング \text{角度マーケットメイキング}

主体は角度を回転し、洗浄し、保険をかけ、監査し、再包装することで利益を得る。

4. シミュレーションが示すこと：角度市場は大きくなり、周辺的ではない

テスト実行では、角度回転は小さな副作用ではなかった。経済活動の重要な一部になった。

長めまたは小規模の複数実行では、累積角度回転はおおよそ：

14% から 34% の累積経済産出 14\% \text{ から } 34\% \text{ の累積経済産出}

明示的な市場：

価値↔善性↔人気 \text{価値} \leftrightarrow \text{善性} \leftrightarrow \text{人気}

はおおよそ：

1,6% から 6,3% の経済産出 1{,}6\% \text{ から } 6{,}3\% \text{ の経済産出}

これら三角市場の手数料はおおよそ：

5,7% から 7,4% 5{,}7\% \text{ から } 7{,}4\%

これは重要である。角度が取引可能になった瞬間、次のような独自産業が生まれることを意味する。

  • 監査
  • コンプライアンス
  • PR
  • 評判取引
  • 角度回転
  • 格付け
  • 政治的ヘッジ
  • 制裁回避
  • 裁判所による修正
  • 道徳的デューデリジェンス

つまりシステムはより倫理的な生産だけを作るのではない。正統性官僚制も作る。

5. 価値は善性と人気を買えるが、対称ではない

これは最重要点の一つである。

あなたのシステムには複数の変換がある。

価値→善性 \text{価値} \rightarrow \text{善性}

価値→人気 \text{価値} \rightarrow \text{人気}

人気→善性 \text{人気} \rightarrow \text{善性}

善性→人気 \text{善性} \rightarrow \text{人気}

しかしこれらの変換は同じ強さではない。

価値 → 善性

これは実際のコストによって可能である。

  • より良い労働条件
  • 清潔なサプライチェーン
  • 環境保護
  • コンプライアンス
  • 監査
  • 補償
  • 製品安全
  • 透明性
  • 損害修復

これは良い形である。

しかし安くなりすぎると、次が生まれる。

道徳的マネーロンダリング \text{道徳的マネーロンダリング}

その場合、買っているのは本当の善性ではなく、より良いラベルだけである。

したがって：

価値→善性 \text{価値} \rightarrow \text{善性}

は、世界が実際に変わった場合にのみ成立すべきであり、主張を買っただけでは成立すべきでない。

価値 → 人気

これははるかに簡単である。

買えるものは：

  • 広告
  • インフルエンサー
  • メディアキャンペーン
  • 割引
  • スポンサーシップ
  • 国民的象徴
  • 娯楽
  • アイデンティティ結合
  • 人工的トレンド

これはすぐに次へつながる。

人気だが、善くない \text{人気だが、善くない}

つまり：

x<0,y>0 x < 0,\quad y > 0

これは最も危険な象限である。

人気 → 善性

これは間接的にしか可能ではない。

人気のある企業は、顧客・従業員・投資家がより多くの時間を与えるため、改革を実施しやすい。人気は社会的委任を生む。

しかし人気は真理ではない。

この変換が強すぎると、システムはポピュリズム化する。

多くの人が好むものは自動的に善いと見なされる。 \text{多くの人が好むものは自動的に善いと見なされる。}

それは致命的である。

善性 → 人気

これは最も遅い変換である。

本当の善性は可視化されたときにだけ人気になる。そのためには必要である。

  • 自由なメディア
  • 信頼
  • 良い教育
  • 機能する裁判所
  • 公共の忍耐
  • 低い分極化

そうでなければ、良い行為は不人気または不可視のまま残る。

ここから厳しい結論が出る。

人気は、善性が可視化されるより速く買える。 \boxed{ \text{人気は、善性が可視化されるより速く買える。} }

したがって強い制度がなければ、システムはPR支配に傾く。

6. 新しいインフレが発生する：角度インフレ

通常のインフレとは：

より多くのお金が同じ財を追いかける \text{より多くのお金が同じ財を追いかける}

角度インフレとは：

多すぎる主体が自分を善く人気があると主張する \text{多すぎる主体が自分を善く人気があると主張する}

しかし信頼度は下がる。

ρ↓ \rho \downarrow

シミュレーションでは平均的な現金信頼度が大きく低下した。複数実行で平均およそ：

0,52 0{,}52

低下した。

これはモデルの強いシグナルである。お金が絶えず混合され、回転され、再解釈され、異なるオラクルによって評価されると、信頼度の摩耗が生じる。

すると形式上は誰もがお金を持っているが、そのお金が本当にどれほど清潔で、善く、人気があり、受け入れられるのか誰も確信できない。

これは次を生む。

信頼割引 \text{信頼割引}

より高いスプレッド \text{より高いスプレッド}

より多い監査コスト \text{より多い監査コスト}

より多い角度回転 \text{より多い角度回転}

より多い保険 \text{より多い保険}

より多いシャドーマーケット \text{より多いシャドーマーケット}

角度インフレは価格上昇ではなく、道徳的シグナルの減価である。

7. 主な勝者は自動的に善い者ではなく、信頼できる善い者である

システムは純粋な善性を報酬しない。報酬するのは：

善性×可視性×信頼度 \text{善性} \times \text{可視性} \times \text{信頼度}

つまり：

V正統=g⋅p可視⋅ρ V_{\text{正統}} = g \cdot p_{\text{可視}} \cdot \rho

本当に善い企業でも、誰にも見えなければあまり得をしない。

中程度に善い企業でも強いメディア力を持てば、より多く勝てる。

悪い企業でも大きなPRを持てば短期的に勝てる。ただし信頼度が崩れない限りである。

したがって勝者は：

道徳的に最善の者ではなく、評判が強く、信頼できる善い者である。 \boxed{ \text{道徳的に最善の者ではなく、評判が強く、信頼できる善い者である。} }

これは現実的だが不快な発見である。

8. システムは企業を規律するが、新しい逃げ道も生む

肯定的効果：

悪い角度は高価になるため、企業には本当に改善する強いインセンティブがある。

θ悪い⇒より高い信用コスト \theta_{\text{悪い}} \Rightarrow \text{より高い信用コスト}

θ悪い⇒より少ない顧客 \theta_{\text{悪い}} \Rightarrow \text{より少ない顧客}

θ悪い⇒より悪い労働供給 \theta_{\text{悪い}} \Rightarrow \text{より悪い労働供給}

θ悪い⇒より多い制裁 \theta_{\text{悪い}} \Rightarrow \text{より多い制裁}

しかし同時に新しい攻撃も生まれる。

  • 角度洗浄
  • 偽の人気
  • 買われた善性
  • 操作された監査

シミュレーションでは、監査罰金、企業スキャンダル、特許、政権交代、時折の企業倒産が繰り返し現れた。これは自然である。角度が経済的に重要になるほど、角度は攻撃される。

一般規則は：

購買力に影響するものはすべて操作される。 \boxed{ \text{購買力に影響するものはすべて操作される。} }

善性が購買力に影響するなら、善性は操作される。
人気が購買力に影響するなら、人気は操作される。

9. 政府と人民は貨幣オラクルになる

あなたのシステムでは、政府が善/悪を定め、人民が人気/不人気を定める。

したがって彼らは方向の中央銀行のようなものになる。

貨幣供給 \text{貨幣供給}

金利 \text{金利}

道徳的方向 \text{道徳的方向}

社会的受容 \text{社会的受容}

信頼度 \text{信頼度}

取引可能性 \text{取引可能性}

これは非常に強力である。

政府が言う：

X社は悪である \text{X社は悪である}

人民が言う：

X社は不人気である \text{X社は不人気である}

政治的闘争は流動性危機になる。 \boxed{ \text{政治的闘争は流動性危機になる。} }

スキャンダルは単なるPR問題ではない。再金融危機を引き起こしうる。

政権交代は単なる権力交代ではない。資産クラス全体を再評価しうる。

10. 正統性ギャップは危機指標になる

最重要指標の一つは：

D=d(θ政府,θ人民) D = d(\theta_{\text{政府}}, \theta_{\text{人民}})

または軸形式では：

D=|善性政府−人気人民| D = |\text{善性}_{\text{政府}} - \text{人気}_{\text{人民}}|

政府が善いと考えるものを人民が嫌うと、テクノクラート的危機が生じる。

人民が愛するものを政府が悪と考えると、ポピュリスト危機が生じる。

シミュレーションは示した。このギャップは自動的には消えない。政治的緊張としてシステム内に残る。

つまり角度は道徳と人気の衝突を解決しない。それを可視化し、取引可能にするだけである。

これは哲学的に重要である。

角度は価値対立をなくさない。それを市場価格にする。 \boxed{ \text{角度は価値対立をなくさない。それを市場価格にする。} }
