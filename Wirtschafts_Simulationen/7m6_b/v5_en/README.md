# Vector Currency Economy Simulation V6 — English Edition

This package is a PyPy3-compatible, standard-library-only simulation of a political economy built around a scalar-and-angle currency:

```text
M = (amount, theta, confidence, origin, history)
theta = atan2(popularity, goodness)
effective purchasing power ≈ amount · confidence · cos(angle_distance / 2)
```

The model combines agent-based behavior, stock-flow style accounting, networked supply chains, financial markets, political institutions, media effects, courts, fraud, environmental ledgers, and dense UTF-8/ANSI terminal dashboards.

## Run

```bash
pypy3 vector_currency_sim.py \
  --steps 24 \
  --countries 3 \
  --households 600 \
  --firms 120 \
  --banks 9 \
  --seed 42 \
  --out metrics.csv \
  --summary summary.json \
  --events events.csv \
  --art \
  --art-every 6
```

Python 3 also works:

```bash
python3 vector_currency_sim.py --steps 24 --art --art-every 6
```

Plain UTF-8 without ANSI color:

```bash
python3 vector_currency_sim.py --steps 24 --art --art-every 6 --no-color
```

## Terminal width safety

The dashboard detects terminal width with `shutil.get_terminal_size()`. The safe rendering width is:

```text
safe_width = terminal_columns - 5
```

All frames, tables, event lines, legends, and long explanations are wrapped inside that safe width. ANSI escape sequences count as zero visible width, and wide Unicode characters are treated conservatively. Explicit `--art-width N` is still capped to the safe terminal width.

## Two angles per actor

Every actor has a buy angle and a sell angle:

```text
buy_angle  = the direction this actor is willing to accept
sell_angle = the direction this actor demands when selling
spread     = circular distance between buy_angle and sell_angle
```

The amount of money is both purchasing power and the weight with which an actor pulls the angle order book.

## V6 English conversion

V6 keeps the V5 mechanics and dashboard structure, but all user-visible script output and documentation have been converted to English. The buy/sell markers have been converted from German-style `K/V` to English-style `B/S`.

## Included mechanisms

- multiple countries and jurisdictions
- governments and courts as good/bad oracles
- peoples, media, and social groups as popular/unpopular oracles
- households, firms, banks, central banks, investment funds, rating agencies, and corporate groups
- product, service, labor, credit, bond, equity, insurance, mortgage, foreign exchange, real-estate, black-market, and angle markets
- supply chains, intermediate inputs, provenance, environmental harm, social benefit, data privacy damage, crime, biodiversity, and health burden
- taxes, subsidies, procurement, elections, protests, propaganda, lobbying, constitutional safeguards, court overrides, and minority-harm tracking
- fraud, corruption, regulatory capture, tax havens, transfer pricing, angle laundering, audits, scandals, strikes, defaults, and crisis shocks
- triadic trading among value, goodness, and popularity
- dense UTF-8/ANSI art dashboards with terminal-safe wrapping

## Output files

The script can write:

- `metrics.csv`: macro, sector, financial, political, environmental, and angle-market metrics
- `summary.json`: final state summary
- `events.csv`: event log
- dashboard text through standard output when `--art` is enabled

## Files in this package

- `vector_currency_sim.py`: main executable script
- `vector_currency_sim_v6.py`: identical V6 copy
- `README.md`: this file
- `ART_DASHBOARD.md`: explanation of the UTF-8/ANSI dashboard
- `COVERAGE.md`: model coverage and limits
- `CHANGELOG_V6.md`: changes from V5 to V6
- demo output files generated by a short smoke test

## Compatibility note

The code uses only Python's standard library. In this environment, `pypy3` was not installed, so compilation and smoke tests were performed with CPython. The script is designed to remain PyPy3-compatible.
