当存在两个角度时，由价值、善良程度和受欢迎程度组成的货币如何流通？

这时，货币不再像一条从买方向卖方的简单流。它作为一种双重流来流通：

商品/服务从卖方流向买方 \text{商品/服务从卖方流向买方}

货币从买方流向卖方 \text{货币从买方流向卖方}

而且这两条流在角度空间中各自都有方向。

核心点是：

每一笔交易都是一次双重角度交换。 \boxed{ \text{每一笔交易都是一次双重角度交换。} }

买方不只是购买产品。
卖方同时也在购买买方的钱。

1. 货币对象

一个货币单位不只由价值构成：

M=m M = m

而是由以下部分构成：

M=(m,g,b,ρ,h) M = (m,g,b,\rho,h)

其中：

m=数值价值 m = \text{数值价值}

g=善良程度 g = \text{善良程度}

b=受欢迎程度 b = \text{受欢迎程度}

ρ=评价的置信度 / 确定性 \rho = \text{评价的置信度 / 确定性}

h=历史 / 来源 h = \text{历史 / 来源}

角度由善良程度和受欢迎程度得出：

θ=atan2⁡(b,g) \theta = \operatorname{atan2}(b,g)

也就是说：

g=x轴：善 vs. 恶 g = \text{x轴：善 vs. 恶}

b=y轴：受欢迎 vs. 不受欢迎 b = \text{y轴：受欢迎 vs. 不受欢迎}

货币的数量是：

m m

方向是：

θ \theta

方向的可信度是：

ρ \rho

因此，一次支付不只是：

100 100

而是例如：

100∠35∘,ρ=0.82 100 \angle 35^\circ,\quad \rho=0.82

这表示：100个价值单位，带有特定的善良/受欢迎方向以及特定的确定性。

2. 每个行为者都有两个角度

每个行为者 ii 都有：

θiK=购买角 \theta_i^K = \text{购买角}

θiV=销售角 \theta_i^V = \text{销售角}

最好的定义是：

θiK=我想接收的方向 \boxed{ \theta_i^K = \text{我想接收的方向} }

θiV=我想支出或出售的方向 \boxed{ \theta_i^V = \text{我想支出或出售的方向} }

也就是说：

  • 购买角是输入过滤器。
  • 销售角是输出信号。

因此，行为者变成了一个角度转换器。

它从一个方向接收东西，并向另一个方向输出东西。

θiK→θiV \theta_i^K \rightarrow \theta_i^V

如果两个角度几乎相同，行为者就是一致的。

如果两个角度相差很远，行为者就通过角度转换赚钱，或者依赖角度转换生存。

3. 每笔交易都有两次角度检查

假设：

  • 买方 AA 从卖方 BB 购买。
  • 卖方 BB 提供产品或服务。
  • 买方 AA 支付货币。

那么有两条流：

产品 / 服务：
B ─────────────────────────▶ A

货币：
A ─────────────────────────▶ B

但现在带有角度：

产品流：
B 以 θ_B^V 出售 ─────▶ A 以 θ_A^K 接收

货币流：
A 以 θ_A^V 支付 ─────▶ B 以 θ_B^K 接收

因此，必须有两个角度距离相匹配：

dX=d(θAK,θBV) d_X = d(\theta_A^K,\theta_B^V)

这是产品流的距离。

以及：

dM=d(θBK,θAV) d_M = d(\theta_B^K,\theta_A^V)

这是货币流的距离。

这一点极其重要。

买方问：

我接收的产品是否适合我的购买角？

卖方问：

我接收的钱是否适合我的购买角？

因为对卖方来说，货币也是被接收的商品。

4. 圆周距离决定可交易性

两个角度之间的距离是：

d(α,β)=arccos⁡(cos⁡(α−β)) d(\alpha,\beta)=\arccos(\cos(\alpha-\beta))

因此：

d∈[0,π] d \in [0,\pi]

也就是说：

d=0 d=0

表示完全兼容。

d=π d=\pi

表示最大对立。

一个简单的兼容函数可以是：

ϕ(d)=cos⁡(d2) \phi(d)=\cos\left(\frac{d}{2}\right)

于是：

d=0⇒ϕ=1 d=0 \Rightarrow \phi=1

d=π⇒ϕ=0 d=\pi \Rightarrow \phi=0

角度越匹配，交易越强。

完整交易需要双方同时满足：

Φ=ϕ(dX)⋅ϕ(dM)⋅ρX⋅ρM \Phi = \phi(d_X)\cdot \phi(d_M)\cdot \rho_X \cdot \rho_M

其中：

dX=产品角度距离 d_X = \text{产品角度距离}

dM=货币角度距离 d_M = \text{货币角度距离}

ρX=产品角度的置信度 \rho_X = \text{产品角度的置信度}

ρM=货币角度的置信度 \rho_M = \text{货币角度的置信度}

如果 Φ\Phi 很高，货币就容易流通。

如果 Φ\Phi 很低，就会出现折价、费用、保险、审计、旋转，甚至没有交易。

5. 交易的流程

一个完整交易如下：

步骤1：买方产生需求

买方 AA 说：

我想要一个方向接近 θAK 的商品 \text{我想要一个方向接近 } \theta_A^K \text{ 的商品}

例如：

θAK=30∘ \theta_A^K = 30^\circ

这意味着：买方寻找善良并且相当受欢迎的东西。

步骤2：卖方提供

卖方 BB 说：

我出售一个方向为 θBV 的商品 \text{我出售一个方向为 } \theta_B^V \text{ 的商品}

例如：

θBV=55∘ \theta_B^V = 55^\circ

那么产品距离为：

dX=25∘ d_X = 25^\circ

这比较接近。买方大概率会接受。

步骤3：买方提出支付

买方 AA 不是用中性货币支付，而是用来自其输出角的货币支付：

θAV \theta_A^V

例如：

θAV=80∘ \theta_A^V = 80^\circ

这笔钱可能非常受欢迎，但善良程度只是中等。

步骤4：卖方检查支付

卖方 BB 对进入的价值有一个购买角：

θBK \theta_B^K

例如：

θBK=70∘ \theta_B^K = 70^\circ

那么货币距离为：

dM=10∘ d_M = 10^\circ

这笔钱很适合卖方。

步骤5：交易执行

如果两个距离都足够小：

dX≤εX d_X \leq \varepsilon_X

dM≤εM d_M \leq \varepsilon_M

那么交易发生。

买方得到产品。

卖方得到钱。

但双方得到的不只是价值，也包括角度质量。

6. 实际流通的是什么？

有三种东西同时流通：

价值 \boxed{ \text{价值} }

善良 \boxed{ \text{善良} }

受欢迎程度 \boxed{ \text{受欢迎程度} }

但它们的流通方式并不相同。

价值通过支付流通

A→B A \rightarrow B

买方失去数值价值。

卖方获得数值价值。

善良通过来源、生产和评价流通

善良通过真实行动产生或消失：

  • 清洁供应链
  • 公平劳动
  • 低损害
  • 好产品
  • 修复损害
  • 合法性
  • 环境影响
  • 社会影响
  • 透明度
  • 审计
  • 法院
  • 政府评价

因此，善良不只是意见。它更强地绑定在真实后果和制度审查上。

受欢迎程度通过接受和注意力流通

受欢迎程度来自：

  • 需求
  • 客户满意度
  • 媒体
  • 潮流
  • 广告
  • 社交网络
  • 文化象征
  • 政治阵营
  • 抵制
  • 抗议
  • 网红
  • 羊群行为

受欢迎程度比善良移动得更快。

因此，它可以更快上升，也可以更快崩塌。

7. 买方的资产负债变化

购买前，买方 AA 拥有：

MA=(mA,gA,bA) M_A = (m_A,g_A,b_A)

他支付：

ΔM=(p,gpay,bpay) \Delta M = (p,g_{\text{pay}},b_{\text{pay}})

于是他的货币存量下降：

mA′=mA−p m_A' = m_A - p

他交出的货币方向是：

θAV \theta_A^V

同时，他得到一个产品：

X=(u,gX,bX) X = (u,g_X,b_X)

其中 uu 是效用，gXg_X 是善良程度，bXb_X 是受欢迎程度。

当产品被消费时，它不会简单地变成钱。它会改变：

  • 效用
  • 生活水平
  • 声誉
  • 未来偏好
  • 政治观点
  • 需求
  • 可能还有自身生产率

对于家庭：

产品→效用 / 满意度 / 观点 \text{产品} \rightarrow \text{效用 / 满意度 / 观点}

对于企业：

产品→投入 / 供应链 / 新生产角 \text{产品} \rightarrow \text{投入 / 供应链 / 新生产角}

这很重要：如果企业购买了一个坏投入，这个坏角度之后可能进入它自己的产品。

8. 卖方的资产负债变化

卖方 BB 交出一个产品：

XB=(u,gX,bX) X_B = (u,g_X,b_X)

并收到货币：

Min=(p,gM,bM) M_{\text{in}} = (p,g_M,b_M)

他的货币存量上升：

mB′=mB+p m_B' = m_B + p

但他的货币质量也会变化：

gB′=gB+gM g_B' = g_B + g_M

bB′=bB+bM b_B' = b_B + b_M

他新的现金角变为：

θBcash=atan2⁡(bB′,gB′) \theta_B^{\text{cash}}= \operatorname{atan2}(b_B',g_B')

如果许多客户用善良且受欢迎的钱支付，企业现金会被拉向这个方向。

如果许多客户用有毒的钱支付，企业现金会被污染。

这意味着：

不仅产品有来源。客户的钱也有来源。 \boxed{ \text{不仅产品有来源。客户的钱也有来源。} }

9. 向量钱包：货币以批次持有

在实践中，一个行为者不应只把钱包存成一个总和。

他有许多货币批次：

Mi={Mi1,Mi2,Mi3,...} M_i = \{M_{i1},M_{i2},M_{i3},...\}

每个批次都有：

(m,g,b,ρ,h) (m,g,b,\rho,h)

例如：

批次 1：500 价值，良好角度，高置信度
批次 2：200 价值，受欢迎但可疑
批次 3：100 价值，有毒，低置信度

当行为者付款时，他选择花哪一笔钱。

这叫作货币选择。

可能的策略：

最好的钱优先

行为者用好钱支付，以获得更好的价格。

最差的钱优先

行为者试图摆脱有毒的钱。

最匹配的钱优先

行为者寻找角度适合卖方购买角的货币批次。

伪装混合

行为者把坏钱和好钱混合，产生可接受的平均角度。

这正是角度洗钱产生的地方。

10. 卖方可以拒绝支付

卖方并不平等地接受所有钱。

他检查：

dM=d(θBK,θAV) d_M = d(\theta_B^K,\theta_A^V)

如果钱距离他的购买角太远，有几种可能：

拒绝

dM>ε⇒没有交易 d_M > \varepsilon \Rightarrow \text{没有交易}

折价

卖方接受这笔钱，但只按折损价值计算：

meff=m⋅ϕ(dM) m_{\text{eff}} = m \cdot \phi(d_M)

例如：

100∠160∘ 100 \angle 160^\circ

对他来说可能只算作：

62 62

加价

买方必须支付更多：

prequired=pϕ(dM) p_{\text{required}} = \frac{p}{\phi(d_M)}

旋转

角度交易商或银行收取费用来旋转货币：

θAV→θBK \theta_A^V \rightarrow \theta_B^K

成本为：

Crot=λmtan⁡2(dM2) C_{\text{rot}}=\lambda m \tan^2\left(\frac{d_M}{2}\right)

角度距离越大，旋转越贵。

审计

检查来源。如果坏角度基于错误信息，置信度或方向可以被修正。

11. 买方可以拒绝产品

同时，买方检查：

dX=d(θAK,θBV) d_X = d(\theta_A^K,\theta_B^V)

如果产品距离希望的购买角太远：

不购买

产品滞销。

降价

卖方必须降价。

产品改善

卖方投资真实改善：

价值→善良 \text{价值} \rightarrow \text{善良}

营销

卖方投资感知：

价值→受欢迎程度 \text{价值} \rightarrow \text{受欢迎程度}

认证

卖方让角度更可信：

ρ↑ \rho \uparrow

这意味着：产品角决定销售能力。

货币角决定支付能力。

12. 两个角度在每笔交易中产生四个角色

在每笔交易中有四个相关角度：

θAK=买方接收产品 \theta_A^K = \text{买方接收产品}

θAV=买方交出货币 \theta_A^V = \text{买方交出货币}

θBK=卖方接收货币 \theta_B^K = \text{卖方接收货币}

θBV=卖方交出产品 \theta_B^V = \text{卖方交出产品}

由此产生两个匹配：

θAK↔θBV \theta_A^K \leftrightarrow \theta_B^V

用于商品。

θBK↔θAV \theta_B^K \leftrightarrow \theta_A^V

用于货币。

这就是完整的流通机制。

                 产品角
          θ_B^V ───────────────▶ θ_A^K
          卖方                    买方


                   货币角
          θ_B^K ◀─────────────── θ_A^V
          卖方                    买方

当两条连接都很短时，交易稳定。

当一条连接短而另一条长时，交易不稳定。

13. 示例：良好交易

买方 AA：

θAK=40∘ \theta_A^K = 40^\circ

θAV=60∘ \theta_A^V = 60^\circ

卖方 BB：

θBK=55∘ \theta_B^K = 55^\circ

θBV=45∘ \theta_B^V = 45^\circ

那么：

dX=d(40∘,45∘)=5∘ d_X = d(40^\circ,45^\circ)=5^\circ

dM=d(55∘,60∘)=5∘ d_M = d(55^\circ,60^\circ)=5^\circ

双方都匹配。

产品适合买方。

货币适合卖方。

交易高度流动。

Φ≈1 \Phi \approx 1

货币很容易流通。

14. 示例：产品匹配，货币不匹配

买方 AA：

θAK=40∘ \theta_A^K = 40^\circ

θAV=150∘ \theta_A^V = 150^\circ

卖方 BB：

θBK=50∘ \theta_B^K = 50^\circ

θBV=45∘ \theta_B^V = 45^\circ

那么：

dX=d(40∘,45∘)=5∘ d_X = d(40^\circ,45^\circ)=5^\circ

产品匹配。

但是：

dM=d(50∘,150∘)=100∘ d_M = d(50^\circ,150^\circ)=100^\circ

货币不匹配。

结果：

  • 买方想买。
  • 卖方想卖。
  • 但卖方不信任这笔钱。
  • 需要加价、旋转、审计或另一种钱。

这就像有购买力却出现支付问题。

买方有价值，但角度错误。

15. 示例：货币匹配，产品不匹配

买方 AA：

θAK=30∘ \theta_A^K = 30^\circ

θAV=60∘ \theta_A^V = 60^\circ

卖方 BB：

θBK=55∘ \theta_B^K = 55^\circ

θBV=150∘ \theta_B^V = 150^\circ

那么：

dM=d(55∘,60∘)=5∘ d_M = d(55^\circ,60^\circ)=5^\circ

货币匹配。

但是：

dX=d(30∘,150∘)=120∘ d_X = d(30^\circ,150^\circ)=120^\circ

产品不匹配。

结果：

  • 卖方很愿意收这笔钱。
  • 买方不想要这个方向的产品。
  • 卖方必须改善、降价或寻找其他买方群体。

这是有偿付能力客户存在时的销售问题。

16. 示例：两个方向都不匹配

买方 AA：

θAK=20∘ \theta_A^K = 20^\circ

θAV=160∘ \theta_A^V = 160^\circ

卖方 BB：

θBK=30∘ \theta_B^K = 30^\circ

θBV=170∘ \theta_B^V = 170^\circ

那么：

dX=d(20∘,170∘)=150∘ d_X = d(20^\circ,170^\circ)=150^\circ

dM=d(30∘,160∘)=130∘ d_M = d(30^\circ,160^\circ)=130^\circ

产品不匹配。

货币不匹配。

交易很可能不会发生，除非在影子市场上，或者以极端折扣发生。

17. 流通作为转换链

每个行为者接收接近其购买角的进入价值：

θK \theta^K

并发出接近其销售角的输出价值：

θV \theta^V

因此，每个行为者都是一种经济角度转换器：

Ti:(m,g,b)in→(m′,g′,b′)out T_i: (m,g,b)_{\text{in}} \rightarrow (m',g',b')_{\text{out}}

或者：

θiK→θiV \theta_i^K \rightarrow \theta_i^V

例子：

企业

购买投入和劳动：

θ企业K \theta^K_{\text{企业}}

生产商品：

θ企业V \theta^V_{\text{企业}}

如果它创造真实质量：

g↑ g \uparrow

如果它做了好的广告：

b↑ b \uparrow

如果它把损害外包：

g↓ g \downarrow

如果它尽管造成损害仍保持受欢迎：

b↑,g↓ b \uparrow,\quad g \downarrow

家庭

接收工资：

θ家庭K \theta^K_{\text{家庭}}

支出消费货币：

θ家庭V \theta^V_{\text{家庭}}

它的购买决策会改变企业的受欢迎程度。

银行

接收存款：

θ银行K \theta^K_{\text{银行}}

发放贷款：

θ银行V \theta^V_{\text{银行}}

它创造新货币，其角度取决于借款人、用途和风险。

政府

接收税收：

θ国家K \theta^K_{\text{国家}}

支出公共资金：

θ国家V \theta^V_{\text{国家}}

它可以通过法律定义善良，并通过支出移动角度。

媒体

接收注意力和金钱：

θ媒体K \theta^K_{\text{媒体}}

输出受欢迎或不受欢迎：

θ媒体V \theta^V_{\text{媒体}}

它们主要影响 bb，即受欢迎程度。

法院 / 审计

接收案件、证据和费用：

θ法院/审计K \theta^K_{\text{法院/审计}}

输出置信度和善良修正：

θ法院/审计V \theta^V_{\text{法院/审计}}

它们主要影响 gg 和 ρ\rho。

18. 最重要的流通公式

对于买方 AA 和卖方 BB 之间的交易：

dX=d(θAK,θBV) d_X = d(\theta_A^K,\theta_B^V)

dM=d(θBK,θAV) d_M = d(\theta_B^K,\theta_A^V)

那么：

交易量=Q⋅ϕ(dX)⋅ϕ(dM)⋅ρX⋅ρM \text{交易量} = Q \cdot \phi(d_X)\cdot \phi(d_M)\cdot \rho_X\cdot\rho_M

或者简写为：

QT=Q0Φ Q_T = Q_0 \Phi

其中：

Φ=ϕ(dX)ϕ(dM)ρXρM \Phi = \phi(d_X)\phi(d_M)\rho_X\rho_M

如果 Φ\Phi 高，流通量就大。

如果 Φ\Phi 低，流通量就小。

如果许多行为者的购买角和销售角不兼容，整个经济的流动性就会下降。

19. 价值如何购买善良

价值可以购买善良，但只能通过真实改变。

例如：

价值→更好的劳动条件 \text{价值} \rightarrow \text{更好的劳动条件}

价值→清洁能源 \text{价值} \rightarrow \text{清洁能源}

价值→损害赔偿 \text{价值} \rightarrow \text{损害赔偿}

价值→产品安全 \text{价值} \rightarrow \text{产品安全}

价值→供应链检查 \text{价值} \rightarrow \text{供应链检查}

于是：

g↑ g \uparrow

一个可能的模拟规则是：

Δg=ηg⋅log⁡(1+Ig)⋅Rreal⋅ρaudit \Delta g = \eta_g \cdot \log(1+I_g)\cdot R_{\text{real}}\cdot \rho_{\text{audit}}

其中：

Ig=对真实改善的投资 I_g = \text{对真实改善的投资}

Rreal=现实因子 R_{\text{real}} = \text{现实因子}

ρaudit=审计置信度 \rho_{\text{audit}} = \text{审计置信度}

如果企业只是声称自己好，却没有真实改善：

Rreal≈0 R_{\text{real}} \approx 0

那么最多只有受欢迎程度短期上升，而不是真实善良上升。

20. 价值如何购买受欢迎程度

价值更容易购买受欢迎程度：

价值→广告 \text{价值} \rightarrow \text{广告}

价值→折扣 \text{价值} \rightarrow \text{折扣}

价值→网红 \text{价值} \rightarrow \text{网红}

价值→媒体活动 \text{价值} \rightarrow \text{媒体活动}

价值→赞助 \text{价值} \rightarrow \text{赞助}

于是：

b↑ b \uparrow

一个可能的模拟规则是：

Δb=ηb⋅log⁡(1+Ib)⋅Mmedia⋅Strend−Bbacklash \Delta b = \eta_b \cdot \log(1+I_b)\cdot M_{\text{media}}\cdot S_{\text{trend}} - B_{\text{backlash}}

其中：

Ib=广告 / 公关支出 I_b = \text{广告 / 公关支出}

Mmedia=媒体放大 M_{\text{media}} = \text{媒体放大}

Strend=趋势因子 S_{\text{trend}} = \text{趋势因子}

Bbacklash=反弹 B_{\text{backlash}} = \text{反弹}

受欢迎程度比善良更快，但更不稳定。

因此经常出现：

b↑,g 保持不变 b \uparrow,\quad g \text{ 保持不变}

甚至：

b↑,g↓ b \uparrow,\quad g \downarrow

这就是：

受欢迎但邪恶 \text{受欢迎但邪恶}

21. 受欢迎程度如何购买善良

受欢迎程度不能直接购买善良，但它可以让改革更容易。

一家受欢迎的企业拥有：

  • 更多客户信任
  • 更多政治资本
  • 更容易获得员工
  • 投资者更有耐心
  • 更高定价能力
  • 对变革更少的阻力

于是它可以把受欢迎程度转化为真实改革能力：

b→g b \rightarrow g

例如：

Δg=ηbg⋅b⋅Ig⋅ρ \Delta g = \eta_{bg}\cdot b \cdot I_g \cdot \rho

但这里也需要真实投资。

受欢迎程度本身不是善良。

它只是一个资源，使善良更容易被生产出来。

22. 善良如何购买受欢迎程度

善良可以产生受欢迎程度，但只有在它变得可见时才可以。

g→b g \rightarrow b

这需要：

  • 透明度
  • 自由媒体
  • 可信审计
  • 可理解的沟通
  • 教育
  • 时间
  • 信任

一个可能的规则：

Δb=ηgb⋅g⋅Tvisibility⋅ρ \Delta b = \eta_{gb}\cdot g \cdot T_{\text{visibility}}\cdot \rho

其中：

Tvisibility=可见性 T_{\text{visibility}} = \text{可见性}

如果没人看到善良，受欢迎程度几乎不会上升。

因此，一个好但不可见的企业可能仍然不受欢迎。

23. 危险流通：角度洗钱

角度洗钱发生在有人把坏价值转换成更好的表面角度时。

例如：

1000∠160∘→900∠40∘ 1000 \angle 160^\circ \rightarrow 900 \angle 40^\circ

但没有真实改善。

这可能通过以下方式发生：

  • 子公司
  • 中介
  • 虚假审计
  • 公关活动
  • 捐赠
  • 购买评级
  • 人工受欢迎程度
  • 机器人网络
  • 税务和角度避风港

于是表面上：

g↑,b↑ g \uparrow,\quad b \uparrow

但置信度应该下降：

ρ↓ \rho \downarrow

而历史 hh 应该变得可疑。

因此系统需要来源轨迹：

h=交易历史 h = \text{交易历史}

没有历史，角度货币就可以被洗白。

24. 劳动力市场中的流通

劳动力市场尤其重要。

企业购买劳动。

工人出售劳动。

对企业来说，劳动是投入：

θ企业K \theta_{\text{企业}}^K

对工人来说，工资是进入价值：

θ工人K \theta_{\text{工人}}^K

同时：

  • 工人用自己的销售角出售劳动力。
  • 企业用自己的销售角支付工资。

因此又有两个匹配：

d劳动=d(θ企业K,θ工人V) d_{\text{劳动}} = d(\theta_{\text{企业}}^K,\theta_{\text{工人}}^V)

d工资=d(θ工人K,θ企业V) d_{\text{工资}} = d(\theta_{\text{工人}}^K,\theta_{\text{企业}}^V)

如果劳动匹配，但工资角差，工人会要求更高工资。

如果工资好，但活动本身差，他仍然可能拒绝。

这解释了真实情况：

高工资，坏雇主 \text{高工资，坏雇主}

低工资，好目的 \text{低工资，好目的}

受欢迎企业，差劳动条件 \text{受欢迎企业，差劳动条件}

不受欢迎职业，高社会价值 \text{不受欢迎职业，高社会价值}

25. 信贷市场中的流通

在信贷中，货币被新创造或在时间上转移。

银行发放信贷：

θ银行V \theta_{\text{银行}}^V

债务人接收信贷：

θ债务人K \theta_{\text{债务人}}^K

之后债务人偿还：

θ债务人V \theta_{\text{债务人}}^V

银行接收还款：

θ银行K \theta_{\text{银行}}^K

因此：

d信贷=d(θ债务人K,θ银行V) d_{\text{信贷}}=d(\theta_{\text{债务人}}^K,\theta_{\text{银行}}^V)

d还款=d(θ银行K,θ债务人V) d_{\text{还款}}=d(\theta_{\text{银行}}^K,\theta_{\text{债务人}}^V)

如果信贷服务于好目的：

g信贷↑ g_{\text{信贷}} \uparrow

如果信贷资助受欢迎的投机：

b信贷↑,g信贷 不确定 b_{\text{信贷}} \uparrow,\quad g_{\text{信贷}} \text{ 不确定}

如果信贷资助有毒活动：

g信贷↓ g_{\text{信贷}} \downarrow

那么利率或抵押要求上升。

利率由以下部分构成：

i=i0+i违约+i角度风险+iρ i = i_0 + i_{\text{违约}} + i_{\text{角度风险}} + i_{\rho}

也就是：

利息=时间价格+风险+角度惩罚 \text{利息} = \text{时间价格} + \text{风险} + \text{角度惩罚}

26. 国家中的流通

国家接收税收：

θ国家K \theta_{\text{国家}}^K

并支出公共资金：

θ国家V \theta_{\text{国家}}^V

来自有毒来源的税收可能有问题：

国家是否应该接受坏钱？ \text{国家是否应该接受坏钱？}

如果接受，也许必须清洁它：

θ有毒→θ公共合法 \theta_{\text{有毒}} \rightarrow \theta_{\text{公共合法}}

通过：

  • 法院
  • 透明度
  • 再分配
  • 修复损害
  • 公共投资

公共支出创造新角度：

  • 教育可以提高 gg。
  • 宣传可以人为提高 bb。
  • 基础设施可以提高价值和善良。
  • 镇压可以短期产生秩序，但长期产生坏角度。
  • 战争可以根据人民和政府而得到非常不同的角度。

因此，国家是一个巨大的角度转换器。

27. 国家之间的流通

每个国家都有自己的坐标轴。

在A国好的东西，在B国不一定好。

因此需要角度翻译：

TA→B(θ) T_{A\rightarrow B}(\theta)

出口交易于是具有：

θ出口, A→TA→B(θ出口, A) \theta_{\text{出口, A}} \rightarrow T_{A\rightarrow B}(\theta_{\text{出口, A}})

例子：

40∘ 在A国 40^\circ \text{ 在A国}

可能变成：

110∘ 在B国 110^\circ \text{ 在B国}

于是出现国际角度套利。

企业寻找这样的国家：

  • 产品更受欢迎
  • 善良被评价得更好
  • 坏影响更不显眼
  • 历史审查更不严格

这是道德地点套利。

28. 多个市场中会发生什么？

每个市场都有自己的角度结构。

产品市场

θ买方K↔θ卖方V \theta_{\text{买方}}^K \leftrightarrow \theta_{\text{卖方}}^V

支付市场

θ卖方K↔θ买方V \theta_{\text{卖方}}^K \leftrightarrow \theta_{\text{买方}}^V

劳动力市场

θ企业K↔θ工人V \theta_{\text{企业}}^K \leftrightarrow \theta_{\text{工人}}^V

以及：

θ工人K↔θ企业V \theta_{\text{工人}}^K \leftrightarrow \theta_{\text{企业}}^V

信贷市场

θ债务人K↔θ银行V \theta_{\text{债务人}}^K \leftrightarrow \theta_{\text{银行}}^V

之后：

θ银行K↔θ债务人V \theta_{\text{银行}}^K \leftrightarrow \theta_{\text{债务人}}^V

资本市场

投资者购买企业股权：

θ投资者K↔θ企业V \theta_{\text{投资者}}^K \leftrightarrow \theta_{\text{企业}}^V

企业购买资本：

θ企业K↔θ投资者V \theta_{\text{企业}}^K \leftrightarrow \theta_{\text{投资者}}^V

角度市场

这里直接交易方向：

(m,g,b)→(m′,g′,b′) (m,g,b) \rightarrow (m',g',b')

同时伴随费用、风险和置信度损失。

29. 两个角度在经济上的含义

购买角与销售角之间的差异，是商业逻辑的核心：

si=d(θiK,θiV) s_i = d(\theta_i^K,\theta_i^V)

这是行为者的角度价差。

小价差

si≈0 s_i \approx 0

行为者在类似方向上买卖。

这意味着：

  • 一致
  • 可信
  • 转换工作少
  • 套利少
  • 高可信度

大价差

si≫0 s_i \gg 0

行为者在一个方向买入，在另一个方向卖出。

这可能是好的，也可能是坏的。

好的版本

他购买坏投入，并真实改善它们。

θK=坏 \theta^K = \text{坏}

θV=好 \theta^V = \text{好}

于是他创造真实价值改善。

坏的版本

他购买坏投入，只是包装得更好再出售。

θK=坏 \theta^K = \text{坏}

θV=表面上好 \theta^V = \text{表面上好}

于是他进行角度洗钱。

榨取型版本

他购买好投入，并出售坏产出。

θK=好 \theta^K = \text{好}

θV=坏 \theta^V = \text{坏}

于是他破坏善良或信任。

30. 流通作为整体经济循环

整体经济于是如下：

家庭
  │ 购买产品
  ▼
企业
  │ 支付工资，购买投入，获取贷款
  ▼
银行 / 资本市场
  │ 为企业和国家融资
  ▼
国家
  │ 征税、监管、补贴
  ▼
媒体 / 民众 / 法院 / 政府
  │ 评价善良、受欢迎程度和置信度
  ▼
角度市场
  │ 旋转、保险、审计并交易方向
  ▼
家庭和企业

价值通过支付流动。

善良通过真实后果和制度判断流动。

受欢迎程度通过需求、媒体和社会接受流动。

置信度通过证明、透明度和争议流动。

历史通过交易链流动。

31. 货币流通变得选择性

在普通货币中：

100=100 100 = 100

在你的系统中：

100∠30∘≠100∠150∘ 100 \angle 30^\circ \neq 100 \angle 150^\circ

因此，货币不再到处平等流通。

会形成区域：

干净的高置信度循环

好钱在可信行为者之间流通。

g↑,b↑,ρ↑ g \uparrow,\quad b \uparrow,\quad \rho \uparrow

那里利率低、交易快、价差小。

受欢迎但可疑的循环

受欢迎的钱流通很快，但有风险。

b↑,g 不确定 b \uparrow,\quad g \text{ 不确定}

那里会出现泡沫和丑闻。

善良但不受欢迎的循环

善良但不受欢迎的活动需要耐心、补贴或教育。

g↑,b↓ g \uparrow,\quad b \downarrow

那里有资金不足的危险。

有毒循环

坏钱在影子市场中流通，或以高折价流通。

g↓,b↓,ρ↓ g \downarrow,\quad b \downarrow,\quad \rho \downarrow

那里利率高、欺诈多、流动性低。

32. 为什么流通不会自动变得道德

一个常见误解是：

如果善良和受欢迎程度嵌入钱中，经济就会自动变好。

不是。

这个系统让道德方向可以交易。

因此它也可以被操纵。

它会导致三种可能形式：

真实改善

价值→真实善良 \text{价值} \rightarrow \text{真实善良}

象征性改善

价值→受欢迎程度 \text{价值} \rightarrow \text{受欢迎程度}

欺诈性改善

价值→表面善良 \text{价值} \rightarrow \text{表面善良}

因此 ρ\rho，也就是置信度，绝对关键。

没有置信度，角度会变成宣传标签。

有了置信度，角度才可以被验证。

33. 最简机制

最短的完整描述是：

行为者通过购买角接收，通过销售角发送。 \boxed{ \text{行为者通过购买角接收，通过销售角发送。} }

每笔交易检查：

商品的销售角是否适合买方的购买角？ \boxed{ \text{商品的销售角是否适合买方的购买角？} }

以及：

货币的销售角是否适合卖方的购买角？ \boxed{ \text{货币的销售角是否适合卖方的购买角？} }

如果是，价值、善良和受欢迎程度就容易流动。

如果不是，就会产生：

  • 折价
  • 加价
  • 旋转
  • 审计成本
  • 保险
  • 等待时间
  • 影子市场
  • 声誉风险
  • 政治冲突

因此，货币流通不再是一个圆，而是一个有向网络：

价值沿兼容角度流动。 \boxed{ \text{价值沿兼容角度流动。} }

善良沿真实改善和认可流动。 \boxed{ \text{善良沿真实改善和认可流动。} }

受欢迎程度沿注意力和赞同流动。 \boxed{ \text{受欢迎程度沿注意力和赞同流动。} }

每个行为者的两个角度决定了它想吸收什么以及向世界输出什么。

经济动力正是由此产生。
