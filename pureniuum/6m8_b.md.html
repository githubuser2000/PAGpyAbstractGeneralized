Universelle Eigenschaften zwischen Zahl und Raum

1. Zahl → Raum (Konstruktion)

  • Produkt (mehrere Zahlen werden zu einem Punkt im Raum kombiniert)
  • Vektorraum (Zahlen bekommen Richtung, Addition und Skalierung)
  • Metrischer Raum (Zahlen definieren Abstände zwischen Punkten)
  • Topologischer Raum (Zahlenrelationen erzeugen „Nähe“ und Struktur ohne konkrete Metrik)
  • Quotientenraum (Zahlen werden identifiziert; Gleichheit erzeugt neue Struktur)
  • Funktionenraum / Potenzmenge (Zahlen erzeugen Raum aller möglichen Abbildungen)
  • Graph (Zahlen werden Knoten, Beziehungen erzeugen Struktur)
  • Wahrscheinlichkeitsraum (Zahlen modellieren Ereignis- und Unsicherheitsstrukturen)
  • Freie algebraische Struktur (Zahlen erzeugen Struktur ohne zusätzliche Einschränkungen)

2. Raum → Zahl (Extraktion / Messung)

  • Koordinaten (Raum wird als Zahlenbeschreibung einzelner Punkte dargestellt)
  • Abstand / Metrik (Geometrie wird auf numerische Distanzen reduziert)
  • Dimension (Raum wird durch Anzahl unabhängiger Richtungen beschrieben)
  • Invarianten (Raum wird durch unveränderliche Zahlen/Strukturen beschrieben)
  • Projektion (Raum wird auf weniger Dimensionen reduziert)
  • Volumen / Maß (Raum wird in eine Zahl für Größe übersetzt)
  • Abstandsmatrix (alle Punktbeziehungen werden in Zahlen kodiert)
  • Symmetriegruppe (Raum wird durch seine invarianten Transformationen beschrieben)
  • Homologie / Fundamentalgruppe π₁ (Raum wird durch algebraische Struktur beschrieben)
  • Funktoren (Raum wird in eine strukturierte algebraische Beschreibung übersetzt)

Kernidee

  • Zahl → Raum: Struktur wird aufgebaut
  • Raum → Zahl: Struktur wird gemessen, reduziert oder kodiert
