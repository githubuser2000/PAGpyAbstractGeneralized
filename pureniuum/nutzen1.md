# Frage

Ich habe eine Liste, wie sich mathematische Objekte durch rekursive Schleifen bzw. rekursive Konstruktionsregeln erzeugen lassen, sodass sich alle mathematischen Objekte aus dieser Liste ableiten lassen.

Wenn ich diese Liste zweidimensional anordne, kann man dann für jedes mathematische Objekt in Kombination mit jedem anderen mathematischen Objekt die jeweilige universelle Eigenschaft bestimmen?

Würde dadurch eine Art universelle Landkarte der Mathematik entstehen, in der nicht nur die Objekte selbst, sondern auch ihre universellen Beziehungen systematisch dargestellt werden?

# Antwort

Das ist eine interessante Idee. Im Kern beschreibt sie etwas zwischen einer generativen Grammatik für mathematische Objekte und einer Landkarte ihrer Beziehungen.

Die Grundannahme lautet:

1. Es gibt eine endliche Liste von Grundobjekten oder Grundoperationen.
2. Durch Rekursion bzw. Schleifen werden daraus komplexere mathematische Objekte erzeugt.
3. Die Objekte werden in einer zweidimensionalen Matrix angeordnet.
4. Für jedes Paar von Objekten wird die universelle Eigenschaft ihrer Beziehung untersucht.

Dann entsteht eine Relationstabelle:

|     | A          | B       | C        |
| --- | ---------- | ------- | -------- |
| A   | ?          | Produkt | Funktor  |
| B   | Koprodukt  | ?       | Pullback |
| C   | Adjunktion | Limit   | ?        |

Die Idee erinnert an:

- das Periodensystem der Mathematik,
- Hasse-Diagramme der Ordnungstheorie,
- Ontologien der Informatik,
- Morphismen-Netzwerke der Kategorientheorie.

Der entscheidende Punkt ist die Rekursion.

Wenn alle mathematischen Objekte tatsächlich durch eine kleine Menge rekursiver Konstruktionsregeln erzeugt werden können, dann wären universelle Eigenschaften letztlich Eigenschaften dieser Erzeugungsprozesse.

Man könnte dann fragen:

„Welche universellen Eigenschaften entstehen zwischen zwei Erzeugungsregeln?“

anstatt:

„Welche universellen Eigenschaften entstehen zwischen zwei fertigen Objekten?“

Dadurch würde sich die Komplexität erheblich reduzieren.

Man könnte Objekte beispielsweise durch Operatoren wie diese beschreiben:

- Produkt
- Summe
- Potenz
- Quotient
- Rekursion
- Fixpunkt
- Kategorie
- Funktor

Jedes mathematische Objekt wäre dann ein Ausdrucksbaum.

Die zweidimensionale Matrix würde nicht einzelne Objekte enthalten, sondern Klassen von Konstruktionsmustern.

Noch weiter gedacht könnte jedes Objekt durch einen Erzeugungsvektor beschrieben werden:

O = (a₁, a₂, ..., aₙ)

wobei aᵢ die Häufigkeit oder Tiefe bestimmter Rekursionsschritte beschreibt.

Die gesamte Mathematik könnte dann als Graph dargestellt werden:

- Knoten = Objekte
- Kanten = universelle Eigenschaften
- Zyklen = Selbstähnlichkeiten
- Höhere Strukturen = Adjunktionen, Limites, Kolimites usw.

Dies würde zu einer Art Koordinatensystem der Mathematik führen.

Die entscheidende Frage bleibt jedoch:

Ist die Erzeugerliste vollständig?

Falls sich tatsächlich alle bekannten mathematischen Strukturen – Mengen, Gruppen, Ringe, Körper, Topologien, Kategorien, Garben, Homotopietypen usw. – aus derselben rekursiven Liste erzeugen lassen, dann wäre die zweidimensionale Anordnung nicht nur eine Klassifikation, sondern eine Meta-Theorie der Mathematik.

Universelle Eigenschaften wären dann möglicherweise berechenbare Einträge einer großen Matrix, anstatt isolierte mathematische Entdeckungen zu sein.

Die gesamte Mathematik könnte als ein einziges rekursiv erzeugtes Netzwerk von Strukturen aufgefasst werden.
