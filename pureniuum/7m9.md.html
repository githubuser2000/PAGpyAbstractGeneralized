Universelle Eigenschaften zwischen Einheit (Element/Variable) und Winkel

Die Beziehung ist eine Dualität zwischen diskreter Struktur (Einheit) und gerichteter, kontinuierlicher Struktur (Winkel).
Sie lässt sich in zwei Richtungen zerlegen:

1. Richtung: Einheit / Element → Winkel

Hier entsteht Winkelstruktur aus einem atomaren oder diskreten Objekt.

Eigenschaften

  • Differenzbildung (Relation statt Objekt)
    Ein Winkel entsteht nur aus der Beziehung zwischen zwei Einheiten (z. B. Vektoren, Zustände).

  • Orientierungs-Induktion
    Eine neutrale Einheit wird durch Vergleich in eine Richtung im Raum eingebettet.

  • Parameter einer Transformation
    Die Einheit wird zum Steuerparameter einer Drehung oder kontinuierlichen Bewegung.

  • Diskret → zyklisch (Periodisierung)
    Lineare Struktur wird durch Modulo-Struktur zu einem Kreisraum (z. B. 2π2\pi-Zyklus).

  • Embedding in kontinuierlichen Raum
    Ein diskretes Element wird in einen kontinuierlichen Raum (z. B. Einheitskreis S1S^1) eingebettet.

  • Komposition erzeugt Richtung
    Mehrere Einheiten erzeugen durch Aggregation einen resultierenden Winkel.

2. Richtung: Winkel → Einheit / Element

Hier wird geometrische Struktur wieder in atomare oder algebraische Elemente zerlegt.

Eigenschaften

  • Skalarisierung (Reduktion auf Zahl)
    Der Winkel wird als einzelne reelle Variable θ\theta kodiert.

  • Projektion auf Basisstrukturen
    Winkel erzeugt Komponenten (z. B. sin⁡(θ)\sin(\theta), cos⁡(θ)\cos(\theta)), die als Einheiten eines Vektors dienen.

  • Normalisierung (Standardisierung)
    Winkel wird auf ein Standardintervall reduziert (z. B. [0,2π)[0, 2\pi)).

  • Äquivalenzklassenbildung
    Verschiedene geometrische Konfigurationen werden als gleiche Einheit klassifiziert.

  • Invarianzextraktion
    Aus der Rotation wird ein invariantes Element (Richtungseinheit auf dem Kreis) extrahiert.

  • Diskretisierung
    Kontinuierliche Winkelstruktur wird in einzelne Einheiten zerlegt (Quantisierung).

Kernintuition

  • Einheit → Winkel:
    Struktur wird Relation → Relation wird Richtung

  • Winkel → Einheit:
    Richtung wird Zahl → Zahl wird Baustein
