Universelle Eigenschaften: Logikprädikat ↔︎ Wahrheitswert (0-stellig) ↔︎ Konkretes / Festes / Hartes

Wir betrachten drei Ebenen:

  • Prädikat: P(x1,…,xn)P(x_1, \dots, x_n) — relationale Struktur
  • 0-stelliges Prädikat: P()∈{wahr,falsch}P() \in \{\text{wahr}, \text{falsch}\} — reiner Wahrheitswert
  • Konkretes/Festes/Hartes: ein „objektartiger Zustand“ ohne Variabilität (statisch, determiniert, nicht-relational)

1. Richtung: Abstraktion → Konkretion

(A) Prädikat → Wahrheitswert / Konkretheit

  • Reduktion von Struktur auf Zustand
    • (Prädikat → Wahrheitswert): Entfernung aller Argumente → Boolescher Zustand
    • (Prädikat → Konkretes): Entfernung aller Variabilität → Fixierung auf einen stabilen Zustand
  • Informationskompression
    • Viele mögliche Relationen → ein einzelner Wahrheitswert
    • Viele mögliche Belegungen → ein „hartes Faktum“
  • Entkopplung von Variablen
    • Freiheitsgrade werden eliminiert
    • Ergebnis ist invariant unter weiteren Eingaben
  • Stabilisierung
    • Dynamisches wird statisch
    • Relationales wird objektartig

(B) 0-stelliges Prädikat → Konkretes / Hartes

  • Identifikation von Wahrheit = Faktizität
    • „wahr“ wird zu einem festen Zustand der Realität
    • keine interne Struktur mehr sichtbar
  • Ontologische Verdichtung
    • Logischer Wert wird als „Objekt“ behandelt
    • Wahrheit ≈ existierender Zustand
  • Nicht-Kompositionalität
    • keine Zerlegung mehr möglich
    • atomarer Charakter

2. Richtung: Konkretion → Abstraktion

(A) Konkretes / Festes → Wahrheitswert / Prädikat

  • Abstraktion eines Zustands
    • Festes Objekt → kann als Aussage modelliert werden
    • „ist gegeben“ → wird zu Wahr/Falsch-Struktur
  • Prädikatisierung
    • Konkretes wird zu P(x)P(x): „x hat Eigenschaft Festigkeit/Härte“
    • Objekt wird zu Argument einer Relation
  • Modalisierung
    • Festigkeit wird interpretierbar als notwendige Eigenschaft
    • Konkretheit wird logisch ausdrückbar

(B) Wahrheitswert → Prädikat

  • Re-Expansion von Binärwerten
    • wahr/falsch → Ausdruck einer zugrunde liegenden Struktur
    • wahr⇒∃x:P(x)\text{wahr} \Rightarrow \exists x: P(x)
  • Rekonstruktion von Struktur
    • ein Bit wird als Schatten eines relationalen Systems interpretiert
    • Minimalinformation verweist auf komplexe Generierungsstruktur
  • Potenzialisierung
    • Wahrheitswert wird als Endpunkt einer Auswertung gesehen
    • dahinter liegende Variablen werden wieder eingeführt

3. Gemeinsame universelle Eigenschaften

(A) Diskretheit vs. Kontinuität der Struktur

  • Prädikat: potentiell kontinuierlich/hochdimensional
  • Wahrheitswert: diskret (0/1)
  • Konkretes: diskret im Sinne von „fixiert“

(B) Reduktion von Freiheit

  • Prädikat: viele Freiheitsgrade (Variablen)
  • Wahrheitswert: keine Freiheitsgrade
  • Konkretes: eingefrorene Freiheitsgrade

(C) Invarianz

  • Alle drei können als invariant unter bestimmten Transformationen interpretiert werden:
    • Prädikat → unter Variablenbelegung
    • Wahrheitswert → unter Strukturänderung (keine Struktur mehr vorhanden)
    • Konkretes → unter Kontextänderung (stabiler Zustand)

(D) Ontologische Verschiebung

  • Prädikat: „Beziehung“
  • Wahrheitswert: „Zustand der Gültigkeit“
  • Konkretes: „Seiendes Objekt“

Alle drei sind unterschiedliche Projektionen desselben Informationskerns.

4. Kurzform der Dualität

  • Abstraktion: Struktur → Zustand → Objekt
  • Rekonstruktion: Objekt → Zustand → Struktur

Kernaussage

Ein Logikprädikat ist ein Raum möglicher Strukturen.
Der Wahrheitswert ist die komprimierte Entscheidung über diesen Raum.
Das Konkrete/Feste/Harte ist die ontologische Fixierung dieses Entscheids als Objektzustand.
