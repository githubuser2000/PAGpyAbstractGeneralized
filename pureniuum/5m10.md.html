Universelle Eigenschaften: Logikprädikat ↔︎ Wahrheitswert (0-stellig) ↔︎ Box / Einheit (≈ 1)

Wir betrachten drei Konzepte auf einer gemeinsamen Strukturachse:

  • Logikprädikat: P(x1,…,xn)P(x_1, \dots, x_n)
  • Nullstelliges Prädikat (Aussage): P()∈{true,false}P() \in \{\text{true}, \text{false}\}
  • Box / Einheit: ein strukturtragendes Objekt, das „Inhalt halten“ kann (analog zur Zahl 1 als neutraler Träger von Skalierung und Identität)

1. Verdichtete Interpretation der drei Objekte

Objekt Typische Rolle Abstrakte Bedeutung
Prädikat P(x)P(x) Relation / Funktion Struktur über Inputs
Nullstelliges Prädikat P()P() Wahrheitswert Struktur ohne Input → reine Gültigkeit
Box / Einheit (≈ 1) Container / Identität Struktur ohne Differenz → reiner Träger

2. Universelle Eigenschaften (beide Richtungen)

A. Von Logikprädikat → Wahrheitswert / Box

  • Reduktion durch Bindung
    • Variablen werden „geschlossen“ → Ergebnis wird konstant
  • Skalarisierung
    • P(x1,…,xn)→WahrheitswertP(x_1,\dots,x_n) \rightarrow \text{Wahrheitswert}
  • Kontextverlust
    • interne Struktur wird irrelevant, nur Stabilität bleibt
  • Fixpunktbildung
    • Ein Zustand wird ausgewählt, der invariant ist
  • Typwechsel
    • Funktion → Objekt (höherer Strukturgrad → Element)

B. Von Wahrheitswert / Box → Logikprädikat

  • Expansion durch Parametrisierung
    • true→P(x)\text{true} \rightarrow P(x) mit trivialer Struktur
  • Strukturaufbau
    • aus statischem Wert wird relationale Form
  • Generalisierung
    • Einzelzustand → Familie von Zuständen
  • Einbettung
    • Wahrheitswert wird als Spezialfall einer Funktion interpretiert
  • Funktionalisierung
    • Objekt → Abbildung auf Raum von Inputs

3. Nullstelligkeit als Grenzform

Nullstelliges Prädikat:

P()∈{true,false} P() \in \{\text{true}, \text{false}\}

Eigenschaften:

  • keine Freiheitsgrade
  • vollständige Kompression einer Struktur
  • reine Zustandsaussage
  • entspricht: „die Welt wurde vollständig ausgewertet“

4. Box ≈ Zahl 1 als strukturelle Identität

Die Box (oder Einheit 1) ist hier keine Zahl im klassischen Sinn, sondern:

  • Identitätsträger
  • neutraler Strukturcontainer
  • Multiplikatives Neutralelement
    • x⋅1=xx \cdot 1 = x

Universelle Eigenschaften:

  • Neutralität
    • verändert nichts, aber hält alles
  • Transportfähigkeit
    • kann Struktur aufnehmen ohne sie zu verändern
  • Selbstgleichheit
    • Box bleibt Box unabhängig vom Inhalt
  • Skalierungsinvarianz
    • wirkt als Referenzpunkt für Vergleich
