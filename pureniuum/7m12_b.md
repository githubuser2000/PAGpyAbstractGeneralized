# Letzte 2 Fragen und Antworten

## Frage 1

Kannst du beide Arten nur kurz listen in 2 Listen?

### Antwort 1

# A) Winkel → Struktur (lokal → global)

_(Winkel = lokale Richtungsinformation → wird zu diskreter Ordnung)_

- Vergleich → Ordnung (Richtung wird zu „vor/nach“)
- Kontinuierlich → diskret (fließende Winkel → feste Objekte)
- Symmetrie → Strukturbruch (Rotation wird „fixiert“ → Information entsteht)
- Nicht-Transitivität → Komplexität (lokale Richtungen passen global nicht perfekt zusammen → Netzwerke entstehen)
- Komposition → Struktur (mehrere Richtungen hintereinander → Pfade/Bäume)
- Stabilität → Cluster/Mengen (ähnliche Winkel werden zusammengefasst)
- Orientierung → Kategorisierung (Richtung entscheidet Zugehörigkeit)

---

# B) Struktur → Winkel (global → lokal)

_(Struktur = feste Relationen → erzeugen implizite Geometrie)_

- Relation → Richtung (A→B wird zu Vektor/Winkel)
- Hierarchie → Winkelgradient (oben/unten wird zu Achse im Raum)
- Graph → geometrischer Raum (Kanten werden zu Abständen + Winkeln)
- Menge → isotroper Raum (keine Relationen → keine Richtung)
- Rekursion → skalierte Winkelräume (jede Ebene hat eigene Orientierung)
- Ordnung → gerichtete Geometrie (Reihenfolge wird räumliche Richtung)
- Komposition → Winkelstruktur (verkettete Relationen erzeugen Pfade im Raum)

---
