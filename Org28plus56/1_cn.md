# 欧盟与数学类型 28–36 的对应

是的——**辅助性原则强烈对应 34**，而不是主要对应 30。  
30 更像是**普遍的有效性条件**：_欧盟究竟是否有权行动？_  
34 是**元概率性的决策区域**：_相对于国家/地区/地方层面的行动，欧盟层面的行动是否更可能更好、更有效、碎片化更少并且合乎比例？_

我会把你的列表这样映射到欧盟：

|   编号 | 数学类型                               | 欧盟对应物                                                 | 为什么                                                                                                                                                                                                                                                                                                                                                                     |
| -----: | -------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **28** | 拓扑 / 组合数学 / 离散数学             | **欧盟的权限与层级空间**                                   | 欧盟不是一个简单的中央集权国家，而是由重叠层级构成的空间：欧盟、成员国、地区、市镇、内部市场、欧元区、申根区、外交政策、预算秩序等等。这更像拓扑—组合结构，而不是层级—线性结构。重要的是：你这里的“28”是一个类型编号，不是当前欧盟国家数量；欧盟目前有 27 个成员国。 [来源](https://european-union.europa.eu/principles-countries-history/eu-countries_en)                 |
| **29** | 态射                                   | **法律行为、程序、权限转移**                               | 态射就是欧盟中的箭头：条例、指令、决定、建议、意见；此外还有立法程序、侵权程序、先行裁决、预算流、授权。欧盟运行条约第 288 条列出了主要的欧盟法律行为：条例、指令、决定、建议和意见。 [来源](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=legissum%3Alegal_acts)                                                                                                    |

## 最干净的简短排序

**28 = 空间**  
欧盟作为权限与层级的拓扑空间。

**29 = 箭头**  
法律行为和程序作为态射。

**30 = 有效性条件**  
有限授权：欧盟行动需要条约依据。

**31 = 本地数据**  
指令、国内转化、本地法律片段：更像预层，而不是层。

**32 = 系统范畴**  
欧盟法律秩序作为由对象和态射构成的范畴。

**33 = 翻译**  
函子：欧盟法被翻译为国家行政、法院和实施实践。

**34 = 不确定性下的决策**  
辅助性原则、比例原则、影响评估、风险。

**35 = 相干操作**  
解释、修改、欧盟法院裁决、法律状态更新。

**36 = 存储**  
EUR-Lex、《官方公报》、登记册、判例法数据库。

## 为什么辅助性原则正好对应 34

辅助性原则不只是一个抽象的普遍原则。它是一个**在信息不完全条件下的比较**：

> 哪个层级更好地解决问题：欧盟、成员国、地区、市镇？

这不是一个关于权限的纯粹是/否问题。它是在评估有效性、碎片化风险、与公民的接近程度、执行成本、内部市场影响以及副作用。正因为如此，辅助性原则属于你的**元概率区域 34**。

清晰的区分会是：

**30：** 欧盟可以行动吗？  
**34：** 欧盟是否应该在这里行动，而不是把事情留在更低层级？  
**35：** 哪个具体操作改变法律状态？  
**36：** 这个状态在哪里被存储、查找和版本化？

所以，你的设定“辅助性原则适合 34”不仅合理，而且在结构上相当强。
